## 1. 채권의 개요와 채권시장 <span class="star s2">★★</span> { #ch1 }

**출제 포인트:** 이자지급 방식별 채권 구분과 옵션부채권이 누구에게 유리한지를 묻는다.

- 이자지급 방식: **이표채**(정기 이자) / **할인채**(선할인, 만기에 액면) / **복리채**(이자 재투자 후 만기 일시지급).
- 옵션부채권

| 채권 | 옵션 보유자 | 유리한 쪽 | 금리 하락 시 |
|---|---|---|---|
| 수의상환채권(callable) | 발행자 | 발행자 | 조기상환 가능성 ↑, 가격 상승 제한 |
| 수의상환청구채권(putable) | 투자자 | 투자자 | — (금리 상승 시 상환청구) |

- 주식 관련 사채: **전환사채(CB)** 전환 시 사채 소멸·신주 발행 / **신주인수권부사채(BW)** 권리 행사 후에도 사채 존속 / **교환사채(EB)** 발행회사가 보유한 다른 주식으로 교환.
- 수의상환채권 가치 = 일반채권 가치 − 콜옵션 가치, 수의상환청구채권 가치 = 일반채권 가치 + 풋옵션 가치.

!!! warning "자주 나오는 함정"
    - 수의상환채권은 투자자가 아니라 **발행자에게 유리** → 일반채권보다 수익률(금리)이 높게 발행.
    - BW는 신주인수권 행사 후에도 **사채가 남는다**(CB와 구분).

## 2. 채권 가격결정과 채권수익률 <span class="star s2">★★</span> { #ch2 }

**출제 포인트:** 할인채·이표채 가격 계산, 경상수익률 계산, 말킬의 채권가격정리 진위 판단.

- 채권 가격 = 미래 현금흐름의 현재가치 합(만기수익률 \(r\) 로 할인)

\[
P = \sum_{t=1}^{n} \frac{C}{(1+r)^t} + \frac{F}{(1+r)^n}
\]

- 할인채: \( P = F/(1+r)^n \). 경상수익률 = 연간 이자 ÷ 채권가격.
- **말킬의 채권가격정리**
    1. 채권가격과 수익률은 **역(−)의 관계**.
    2. 만기가 길수록 같은 수익률 변동에 대한 가격 변동폭이 크다.
    3. 그 변동폭의 증가율은 만기가 길어질수록 **체감**한다.
    4. 같은 폭의 수익률 변동이면 **하락 시 가격 상승폭 > 상승 시 가격 하락폭**.
    5. 표면이자율이 **낮을수록** 가격 변동률이 크다.
- 만기수익률(YTM)은 내부수익률 개념: 현금흐름이 그 수익률로 재투자된다는 가정이 있다.

!!! warning "자주 나오는 함정"
    - "만기가 길어질수록 가격변동폭이 **체증**한다" → 틀림(**체감**).
    - 표면이자율이 높을수록 가격 변동률이 크다 → 틀림.

## 3. 듀레이션과 볼록성 <span class="star s3">★★★</span> { #ch3 }

**출제 포인트:** 맥컬리 듀레이션 계산, 수정듀레이션을 이용한 가격변화율 계산, 듀레이션·볼록성의 성질 비교가 매회 출제된다.

- **맥컬리 듀레이션**: 현금흐름 발생 시점을 현재가치 비중으로 가중평균한 **가중평균 회수기간**

\[
D = \frac{\sum_{t=1}^{n} t \cdot \dfrac{CF_t}{(1+r)^t}}{P}
\]

- **수정듀레이션**: 연 \(m\)회 이자지급이면 \( D_{mod} = \dfrac{D}{1 + r/m} \) (연 1회 지급 시 \( D/(1+r) \)).
- 가격변화율 근사(듀레이션만): \( \dfrac{\Delta P}{P} \approx -D_{mod} \cdot \Delta r \)
- 볼록성까지 반영:

\[
\frac{\Delta P}{P} \approx -D_{mod}\,\Delta r + \frac{1}{2}\, C\,(\Delta r)^2
\]

- (기본서·문제에 따라 ½을 볼록성 값 \(C\) 안에 포함해 \(C(\Delta r)^2\)로 쓰기도 함 → 문제에 주어진 정의를 따를 것, 최신 기본서 확인)
- 예: \( D_{mod}=4 \), 금리 1%p 상승 → 가격 약 **−4%**.
- 특수 케이스: **할인채(무이표채) 듀레이션 = 잔존만기**, 이표채는 만기보다 짧다. 영구채 \( D = (1+r)/r \).
- 듀레이션 성질

| 요인 ↑ | 듀레이션 |
|---|---|
| 잔존만기 | ↑ (일반적) |
| 표면이자율 | ↓ |
| 만기수익률 | ↓ |
| 이자지급 횟수 | ↓ |

- 볼록성: 가격-수익률 곡선은 원점에 대해 볼록 → 듀레이션 직선 근사는 **금리 상승 시 가격하락을 과대평가, 금리 하락 시 가격상승을 과소평가**.
- 볼록성이 큰 조건: **다른 조건이 같다면** 표면이자율 낮을수록, 만기 길수록, 수익률 낮을수록 볼록성 ↑.
- **듀레이션이 같다면** 현금흐름이 넓게 분산된 채권(바벨형 등)의 볼록성이 더 크고, 볼록성 큰 채권이 유리.
- 포트폴리오 듀레이션·볼록성 = 개별 채권 값의 **시장가치 가중평균**.
- 수의상환채권은 금리 하락 구간에서 **음(−)의 볼록성**을 보일 수 있다.

!!! warning "자주 나오는 함정"
    - 표면이자율이 높을수록 듀레이션이 **짧아진다**.
    - 옵션이 없는 일반 채권(양의 볼록성)이면 볼록성 조정항은 금리 방향과 관계없이 **(+)**. 음의 볼록성(수의상환채 등)이면 (−).
    - 이자지급 횟수가 많아지면(연 1회 → 반기) 듀레이션은 **짧아진다**.

## 4. 금리체계 <span class="star s2">★★</span> { #ch4 }

**출제 포인트:** 기간구조 이론별 수익률곡선 해석과 선도금리 계산이 출제된다(거시경제 단원과 겹침).

- **불편기대이론**: 장기금리 = 미래 단기금리 기대치의 평균. 내재 선도금리 = 기대 현물금리.
- **유동성프리미엄이론**(편중기대이론의 하나): 장기채에는 유동성 프리미엄이 붙음 → 단기금리 기대가 일정해도 수익률곡선 **우상향**.
- **시장분할이론**: 만기별 시장이 분리되어 각 시장의 수급으로 금리 결정.
- **선호영역이론(특정시장선호)**: 선호 만기가 있으나 충분한 프리미엄이 있으면 다른 만기로 이동.
- 내재 선도금리(2기간): \( (1+{}_0R_2)^2 = (1+{}_0R_1)(1+{}_1f_1) \)
- 위험구조: 신용스프레드는 일반적으로 **경기 확장기 축소, 수축기 확대**.

!!! warning "자주 나오는 함정"
    - 불편기대이론에서 우상향 곡선 = 미래 단기금리 **상승 예상**. 유동성프리미엄이론에서는 우상향이어도 금리 상승 예상이라고 단정할 수 없다.

## 5. 채권운용전략 <span class="star s3">★★★</span> { #ch5 }

**출제 포인트:** 바벨형·사다리형·불릿형 비교, 면역전략 조건, 채권교체·수익률곡선 타기 같은 적극적 전략의 이름과 상황을 매칭하는 문제가 매회 나온다.

| 구분 | 적극적 전략 | 소극적 전략 |
|---|---|---|
| 전제 | 금리 예측 가능, 시장 비효율 | 시장 효율, 예측 어려움 |
| 예 | 금리예측 전략, 채권교체, 수익률곡선 타기, 나비형/역나비형 | 만기보유, 사다리형, 바벨형, 인덱싱, 면역전략 |

- 금리 하락 예상 → **듀레이션 확대**(장기채·저쿠폰채 매입), 상승 예상 → 듀레이션 축소.
- **채권교체**: 시장 불균형(동일 조건 채권 간 가격 차) 이용 교체, 스프레드 변화 이용 교체 등.
- **수익률곡선 타기(riding)**: 우상향 곡선에서 잔존만기가 줄며 수익률이 하락하는 효과(**롤링효과**, 단기 구간은 **숄더효과**)를 이용, 만기 전 매도.
- 만기 구성 전략

| 전략 | 구성 | 특징 |
|---|---|---|
| 사다리형 | 단기~장기 균등 분산 | 소극적, 위험 평준화 |
| 바벨형 | 단기 + 장기만 보유 | 중기물 없음, 볼록성 큼 |
| 불릿형 | 특정 만기(중기)에 집중 | — |

- 나비형 투자전략: 중기물 금리가 상대적으로 **상승**(곡선 중간이 볼록해짐) 예상 시 **바벨형**이 유리, 역나비형(중기 금리 상대 하락) 예상 시 불릿형 유리.
- **면역전략**: 포트폴리오 **듀레이션 = 목표 투자기간** 으로 맞춰 가격위험과 재투자위험을 상쇄. 금리 변화·시간 경과에 따라 지속적 재조정 필요.
- 현금흐름 일치전략, **상황대응적 면역전략**(목표수익 보장 하한 확보 후 적극 운용) 등 혼합 전략.

!!! warning "자주 나오는 함정"
    - 면역전략은 듀레이션을 **만기**가 아니라 **투자기간**에 맞춘다.
    - 금리 하락 예상 시 듀레이션을 **늘린다**. 줄인다는 보기 주의.
    - 수익률곡선 타기는 **우상향** 곡선이 유지될 때 효과가 있다.
