!!! tip "이 단원 공략법"
    기출복원에서는 **CAPM(가정·SML 계산)**과 **포트폴리오 표준편차·공분산 계산**이 매 회차 나온다. CAPM은 투자운용결과분석의 트레이너·젠센 지표와 바로 연결되므로 먼저 공부한다.
    이어서 단일지표모형 분산 분해와 APT의 CAPM 대비 장점을 비교표로 정리한다.

## 1. 포트폴리오 관리의 기본체계 <span class="star s1">★</span> { #ch1 }

**출제 포인트:** 지배원리와 위험회피 성향(무차별곡선) 개념 문제.

- 기대수익률 \( E(R) = \sum p_i R_i \), 분산 \( \sigma^2 = \sum p_i [R_i - E(R)]^2 \).
- **지배원리**: 같은 위험이면 기대수익 높은 것, 같은 기대수익이면 위험 낮은 것 선택 → 효율적 증권 선별.
- 위험회피형 투자자의 무차별곡선은 **우상향·아래로 볼록**하며, 위험회피도가 클수록 **기울기가 가파르다**.
- 효용함수의 구체적 형태(위험회피계수 표기)는 기본서 표기를 따를 것 (최신 기본서 확인).

## 2. 포트폴리오 관리 <span class="star s3">★★★</span> { #ch2 }

**출제 포인트:** 2자산 포트폴리오 분산·표준편차 계산, 상관계수에 따른 분산효과, 공분산·상관계수 범위, 무위험자산 결합 시 투자기회선이 출제된다.

- 2자산 포트폴리오

\[
E(R_p) = w_1 E(R_1) + w_2 E(R_2)
\]

\[
\sigma_p^2 = w_1^2\sigma_1^2 + w_2^2\sigma_2^2 + 2 w_1 w_2 \rho_{12}\sigma_1\sigma_2
\]

- 공분산 \( \text{Cov}(R_1,R_2) = \rho_{12}\sigma_1\sigma_2 \). 상관계수 범위 **\(-1 \le \rho \le 1\)** (공분산은 범위 제한 없음).
- \( \rho = +1 \): 분산효과 없음(표준편차도 가중평균). \( \rho < 1 \)이면 분산효과 발생. **\( \rho = -1 \)**: 위험을 **0**으로 만드는 비중 존재.
- 최소분산 포트폴리오 비중: \( w_1 = \dfrac{\sigma_2^2 - \text{Cov}_{12}}{\sigma_1^2 + \sigma_2^2 - 2\,\text{Cov}_{12}} \)
- 종목 수를 늘리면 **비체계적 위험**은 줄지만 **체계적 위험**은 남는다.
- 효율적 투자선(efficient frontier): 위험자산만의 효율적 포트폴리오 집합. 최적 포트폴리오 = 효율적 투자선과 **무차별곡선의 접점**.
- 무위험자산 결합 시 **투자기회선(자본배분선)**: \( E(R_p) = R_f + \dfrac{E(R_A) - R_f}{\sigma_A}\,\sigma_p \) → 기울기(보상비율)가 가장 큰 접점 포트폴리오 선택.
- 무위험자산과 위험자산 결합 포트폴리오의 표준편차 = 위험자산 비중 × 위험자산 표준편차.
- 예: \( w_1=w_2=0.5,\ \sigma_1=20\%,\ \sigma_2=10\%,\ \rho=0 \) → \( \sigma_p^2 = 0.25(0.04) + 0.25(0.01) = 0.0125 \), \( \sigma_p \approx 11.2\% \).

!!! warning "자주 나오는 함정"
    - 상관계수가 −1일 때 분산효과 **최대**, +1일 때 분산효과 **없음**.
    - 분산투자로 제거되는 것은 **비체계적 위험**뿐.
    - 상관계수와 달리 공분산은 −1~1 범위로 제한되지 않는다.

## 3. 자본자산 가격결정 모형 <span class="star s3">★★★</span> { #ch3 }

**출제 포인트:** CAPM 기본가정, CML과 SML 비교, SML로 기대수익률·베타 계산, 과대·과소평가 판단이 매회 출제된다.

- **기본가정**: 평균-분산 기준으로 투자, **동질적 기대**, 단일 투자기간, **무위험이자율로 무제한 차입·대출**, 세금·거래비용 없는 완전시장, 가격수용자.
- 시장포트폴리오: 모든 위험자산을 시가총액 비율로 포함, 효율적 포트폴리오.
- **CML(자본시장선)**: 효율적 포트폴리오만 대상

\[
E(R_p) = R_f + \frac{E(R_m) - R_f}{\sigma_m}\,\sigma_p
\]

- **SML(증권시장선)**: 모든 자산·포트폴리오 대상

\[
E(R_i) = R_f + \beta_i\,[E(R_m) - R_f], \qquad \beta_i = \frac{\text{Cov}(R_i, R_m)}{\sigma_m^2}
\]

| 구분 | CML | SML |
|---|---|---|
| 위험 척도 | 총위험 \(\sigma\) | 체계적 위험 \(\beta\) |
| 적용 대상 | 효율적 포트폴리오 | 모든 자산 |

- 포트폴리오 베타 = 개별 베타의 가중평균. 시장 베타 = 1, 무위험자산 베타 = 0.
- 판단: 기대(예상)수익률이 SML **위** → 과소평가(**매수**), SML **아래** → 과대평가(매도).
- 예: \( R_f = 3\%,\ E(R_m)=8\%,\ \beta=1.2 \) → \( E(R) = 3 + 1.2 \times 5 = 9\% \).

!!! warning "자주 나오는 함정"
    - 개별 주식은 CML이 아니라 **SML** 위에 놓인다.
    - CAPM에서 보상받는 위험은 **체계적 위험(베타)**뿐.
    - "투자자마다 기대가 다르다"는 CAPM 가정이 아님(동질적 기대).

## 4. 단일 지표 모형 <span class="star s2">★★</span> { #ch4 }

**출제 포인트:** 분산 분해 공식, 공분산 계산, 마코위츠 모형 대비 추정치 수 비교.

- 모형: \( R_i = \alpha_i + \beta_i R_m + \varepsilon_i \)
- 분산 분해: \( \sigma_i^2 = \beta_i^2\sigma_m^2 + \sigma^2(\varepsilon_i) \) → **체계적 위험 + 비체계적(잔차) 위험**
- 두 종목 공분산: \( \text{Cov}(R_i, R_j) = \beta_i\beta_j\sigma_m^2 \)
- 결정계수 \( R^2 = \dfrac{\beta_i^2\sigma_m^2}{\sigma_i^2} \): 총위험 중 체계적 위험 비율.
- 필요 추정치 수: 마코위츠 완전공분산 모형 \( \dfrac{n(n+3)}{2} \) vs 단일지표모형 **\( 3n + 2 \)**.

!!! warning "자주 나오는 함정"
    - 단일지표모형은 잔차끼리 **상관관계가 없다**고 가정한다.

## 5. 차익거래 가격결정이론 <span class="star s2">★★</span> { #ch5 }

**출제 포인트:** APT의 가정과 CAPM 대비 장점을 묻는 비교 문제.

- 수익률이 여러 공통 요인에 의해 결정: \( E(R_i) = \lambda_0 + b_{i1}\lambda_1 + b_{i2}\lambda_2 + \cdots + b_{ik}\lambda_k \)
- 핵심 가정: 균형시장에서 **무위험 차익거래 기회가 존재하지 않는다**.

| 구분 | CAPM | APT |
|---|---|---|
| 요인 수 | 시장 1개 | 다수 |
| 시장포트폴리오 | 필요 | **불필요** |
| 수익률 분포·효용함수 가정 | 평균-분산 가정 필요 | 상대적으로 약한 가정 |
| 한계 | 시장포트폴리오 관찰 불가 | **요인이 무엇인지 명시하지 않음** |

!!! warning "자주 나오는 함정"
    - APT는 시장포트폴리오가 **필요 없다**. 대신 요인의 수와 종류를 이론이 알려주지 않는다.

## 6. 포트폴리오 투자전략과 투자성과평가 <span class="star s2">★★</span> { #ch6 }

**출제 포인트:** 소극적·적극적 전략 구분과 트레이너-블랙 모형 개념, 성과지표 계산이 출제된다.

- **소극적 전략**: 시장 효율 가정, 인덱스 펀드 등 시장포트폴리오 보유.
- **적극적 전략**: 시장 비효율 이용, 시점선택·종목선택으로 초과수익 추구.
- **트레이너-블랙 모형**: 시장지수(소극적) + 알파가 있는 종목들로 만든 **적극적 포트폴리오**를 결합. 적극적 포트폴리오 내 종목 비중은 \( \alpha_i / \sigma^2(\varepsilon_i) \) 에 비례 (세부 서술은 최신 기본서 확인).
- 성과평가: 샤프 \( \dfrac{R_p - R_f}{\sigma_p} \), 트레이너 \( \dfrac{R_p - R_f}{\beta_p} \), 젠센 \( \alpha_p = R_p - [R_f + \beta_p(R_m - R_f)] \) → [투자운용결과분석](performance.md#ch4) 참고.
