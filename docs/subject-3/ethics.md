## 1. 직무윤리 일반 <span class="star s2">★★</span> { #ch1 }

**출제 포인트:** 법과 윤리의 관계, 직무윤리의 적용대상, 2대 기본원칙을 묻는 개념형 문제가 나온다.

- **법은 최소한의 윤리**: 윤리는 법보다 넓은 개념이며, 직무윤리 중 상당 부분은 법제화되어 있다(위반 시 법적 제재까지 가능).
- 직무윤리는 금융투자업 종사자의 **신뢰(Trust)** 를 바탕으로 하며, 금융투자업은 고객자산을 다루고 정보비대칭이 커서 다른 산업보다 높은 윤리가 요구된다.
- **적용대상**: 투자 관련 직무에 종사하는 **일체의 자** — 회사와의 고용관계·보수 유무, 자격 보유 여부와 무관. 정식 계약 전의 잠재적 고객에 대해서도 적용.
- **2대 기본원칙**
    - 고객우선 원칙: 고객의 이익 > 회사의 이익 > 임직원 개인의 이익
    - 신의성실 원칙: 윤리적 의무이자 **법적 의무**(권리 행사·의무 이행의 기준)
- 윤리경영은 장기적으로 기업 가치·생존에 기여한다(윤리는 "보이지 않는 자산", 비윤리는 비용).

!!! warning "자주 나오는 함정"
    - "무보수·무자격자는 적용대상이 아니다" → 틀림(일체의 자).
    - 신의성실 원칙을 "윤리적 의무일 뿐 법적 의무는 아니다"로 내는 지문 → 틀림.

## 2. 금융투자업 직무윤리 <span class="star s3">★★★</span> { #ch2 }

**출제 포인트:** 이해상충 관리 절차, 금융소비자보호의무(금소법 판매원칙), 본인·회사·사회에 대한 의무를 사례형으로 묻는다. 단원 출제의 중심.

**① 이해상충방지의무**

- 이해상충 발생 원인: 사적 이익 추구, 정보 비대칭, 겸영 업무 확대.
- 관리 순서: 이해상충 가능성 **파악·평가** → 투자자에게 **알림(공시)** → 문제없는 수준으로 **낮춤** → 낮추기 곤란하면 **거래 자체를 하지 않음**.
- 정보교류차단(Chinese Wall), 자기거래 금지(고객의 거래상대방이 되는 행위 금지), 과당매매 금지.

**② 금융소비자보호의무** (2021.3.25 금융소비자보호법 시행 이후 기준)

| 금소법 6대 판매원칙 | 핵심 |
|---|---|
| 적합성 원칙 | 투자권유 시 고객정보 파악 → 부적합 상품 권유 금지 (Know Your Customer) |
| 적정성 원칙 | 권유 **없이** 파생상품 등 위험상품을 사려 할 때 적정성 판단 후 부적정하면 고지·확인 |
| 설명의무 | 중요사항을 이해할 수 있도록 설명, 설명서 제공·확인 |
| 불공정영업행위 금지 | 우월적 지위 이용(꺾기 등) 금지 |
| 부당권유행위 금지 | 단정적 판단 제공, 허위사실, 불초청권유·재권유 금지 |
| 광고 관련 준수사항 | 허위·과장광고 금지, 필수 기재사항 |

- 6대 원칙 위반 등에 대해 금융위는 **관련 수입 등의 50% 이내** 과징금 부과 가능(일부 원칙 대상, 최신 기본서 확인).
- 설명의무 위반 손해배상 소송에서 **고의·과실 입증책임은 판매업자**에게 전환.
- 금융소비자의 권리: 청약철회권, **위법계약해지권**(위법 사실을 안 날부터 1년 이내, 계약일부터 5년 이내), 자료열람요구권.
- 재권유 금지의 예외: 거부 후 **1개월** 경과 후 재권유, 다른 종류의 상품 권유는 가능.
- 상품 판매 이후에도 보고·정보 제공 등 **판매 후 단계**까지 보호의무가 이어진다.

**③ 본인·회사·사회에 대한 의무**

- 본인: 법규 준수, 자기혁신, 품위유지, 사적 이익 추구 금지(부당한 금품 수수, 직무상 정보 이용 금지).
- 회사: 상호존중, 공용재산 사적 사용 금지, 정보보호, 위반행위 보고, 대외활동 시 사전승인, **고용기간 종료 후에도** 비밀유지 의무 지속.
- 사회: 시장질서 존중(**시장질서 교란행위**는 목적성 불요), 주주가치 극대화, 사회적 책임.

!!! warning "자주 나오는 함정"
    - 이해상충을 "공시만 하면 거래 가능"으로 내는 지문 → 낮추기 곤란하면 거래 중단.
    - 적합성(권유 있음) vs 적정성(권유 없음) 뒤바꾸기.
    - 퇴직 후에는 회사 정보 비밀유지 의무가 없다 → 틀림.

## 3. 직무윤리의 준수절차 및 위반 시의 제재 <span class="star s2">★★</span> { #ch3 }

**출제 포인트:** 준법감시인의 지위·임면, 내부통제 장치, 위반 시 제재 주체·종류를 구분하는 문제.

- **내부통제기준**: 회사가 법령 준수·건전경영을 위해 정하는 기준. 제정·변경은 **이사회 결의**.
- **준법감시인**: 이사회 결의로 임면, **해임 시 이사 총수의 2/3 이상 찬성**, 임기 **2년 이상**. 영업실적과 연동된 보수·평가 금지, 독립성 보장.
- 내부통제 장치: 내부제보(Whistle-blower) 제도, 명령휴가제도, 직무분리, 영업점별 영업관리자.
- 2024년 지배구조법 개정으로 **책무구조도** 도입(임원별 내부통제 책임 배분, 적용 시기 최신 기본서 확인).
- 위반 시 제재

| 구분 | 내용 |
|---|---|
| 자율규제 | 금융투자협회의 회원사·임직원 제재 |
| 행정제재 | 금융위·금감원: 회사(인가·등록 취소, 영업정지 등), 임원(해임요구·직무정지·문책경고·주의적 경고·주의), 직원(면직·정직·감봉·견책·주의 등) |
| 민사책임 | 법률행위 무효·취소, 계약 해제·해지, 손해배상 |
| 형사책임 | 법에 규정된 행위에 한해 처벌(양벌규정 포함) |
| 시장통제 | 평판 하락, 고객 이탈 — 법적 제재 아님 |

!!! warning "자주 나오는 함정"
    - 준법감시인 해임을 "이사회 과반수"로 내는 지문 → 2/3 이상.
    - 협회 자율규제를 행정제재로 분류하는 지문 → 틀림.
