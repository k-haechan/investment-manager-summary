## 1. 운용과정과 주식투자 <span class="star s2">★★</span> { #ch1 }

**출제 포인트:** 투자관리 과정의 순서, 자산배분과 증권선택의 구분, 주가지수 산출방식 비교가 개념형으로 출제된다.

- 투자관리 과정: **계획(Plan) → 실행(Do) → 성과평가(See)** 의 순환 구조. 실행 단계에서 자산배분·증권선택·매매가 이뤄진다.
- 투자관리의 3요소: **자산배분**(자산집단 간 비중) / **증권선택**(자산집단 내 종목) / **시점선택**(market timing).
- 장기 성과의 대부분은 증권선택보다 **자산배분**에서 결정된다는 것이 일반적 견해.
- 주가지수 산출방식

| 방식 | 대표 지수 | 특징 |
|---|---|---|
| 가격가중 | 다우존스산업평균, 니케이225 | 고가주의 영향이 큼 |
| 시가총액가중 | KOSPI, KOSPI200, S&P500 | 대형주 영향 큼, 지수 추종 시 리밸런싱 부담 적음 |
| 동일가중 | 일부 동일가중지수 | 소형주 영향 상대적으로 큼 |

!!! warning "자주 나오는 함정"
    - 니케이225는 시가총액가중이 아니라 **가격가중**.
    - "증권선택이 장기 성과의 대부분을 결정한다"는 틀린 진술.

## 2. 자산배분 전략의 정의 및 준비사항 <span class="star s1">★</span> { #ch2 }

**출제 포인트:** 자산집단의 요건과 기대수익률 추정 방법의 이름을 고르는 문제.

- 자산집단의 요건: **동질성**(집단 내), **배타성**(집단 간 중복 없음), 분산투자 효과가 있을 것, 충분히 큰 규모.
- 기대수익률 추정: **추세분석법**, **시나리오분석법**, **펀더멘털분석법**, **시장공동예측치 사용법**.
- 위험은 보통 수익률의 분산(표준편차)으로 측정한다.

## 3. 전략적 자산배분 <span class="star s2">★★</span> { #ch3 }

**출제 포인트:** 전략적 vs 전술적 자산배분의 성격 비교, 전략적 자산배분의 실행 방법 이름.

- 정의: 장기 투자목표·제약조건에 맞춰 **장기적인 자산구성 비율**을 정하는 의사결정. 중단기 시장 변동에는 원칙적으로 대응하지 않는다.
- 이론적 배경: 마코위츠 평균-분산 최적화 → **효율적 투자곡선** 위의 포트폴리오 중 투자자 효용에 맞는 점 선택.
- 실행 방법: **시장가치 접근법**, **위험-수익 최적화 방법**, 투자자별 특수상황 고려 방법, **다른 유사한 기관투자자의 자산배분 모방**.
- 한계: 입력변수(기대수익·공분산) 추정오차에 최적해가 민감 → 극단적 비중이 나오기 쉬움.

| 구분 | 전략적 자산배분 | 전술적 자산배분 |
|---|---|---|
| 기간 | 장기 | 중단기 |
| 성격 | 정적, 기본 골격 | 동적, 저평가 자산 비중 조절 |
| 전제 | 시장 효율성에 가까운 관점 | 단기적 가격 착오(과잉반응) 존재 |

!!! warning "자주 나오는 함정"
    - 전략적 자산배분은 시장 상황 변화에 맞춰 **수시로 비중을 바꾸지 않는다**.

## 4. 전술적 자산배분 <span class="star s2">★★</span> { #ch4 }

**출제 포인트:** 전술적 자산배분의 성격(역투자)과 실행 도구 이름을 묻는 문제.

- 정의: 시장 변화를 반영해 자산 비중을 중단기로 조정, **저평가 자산 매수·고평가 자산 매도**로 초과수익 추구.
- 이론 배경: 증권시장의 **과잉반응**과 평균반전 → 본질적으로 **역투자전략(contrarian)**.
- 실행 도구: **가치평가모형**(기본적 분석, 요인모형), **기술적 분석**, **포뮬러 플랜**(정액법·정률법 등, 가격 하락 시 매수·상승 시 매도).
- 투자자의 위험허용도는 시장 상황과 관계없이 **일정**하다고 가정(보험자산배분과 대비).

!!! warning "자주 나오는 함정"
    - 전술적 자산배분 = 추세추종이 아니다. 기본 성격은 **역투자**.
    - 위험허용도가 시장에 따라 변하는 것은 보험자산배분 쪽 설명.

## 5. 보험자산배분 <span class="star s3">★★★</span> { #ch5 }

**출제 포인트:** 보험전략에서 투자자의 위험회피 성향 변화, CPPI 주식투자금액 계산, 옵션 복제 개념이 반복 출제된다.

- 목적: 투자기간 말 **최저 보장가치(floor)**를 확보하면서 상승 시 수익 참여. 사전에 정한 하한을 지킨다는 점에서 **위험회피적**.
- 위험허용도 가정: 포트폴리오 가치가 오르면 위험허용도 ↑(위험자산 비중 ↑), 떨어지면 위험허용도 ↓(위험자산 비중 ↓) → **추세추종(순응)적** 매매.
- 옵션 이용(OBPI): 주식 + 풋 매수(방어적 풋), 또는 채권 + 콜 매수. 옵션이 없거나 만기가 맞지 않으면 **동적 자산배분**으로 옵션을 복제(합성).
- CPPI(고정비율 포트폴리오 보험)

\[
\text{쿠션} = \text{포트폴리오 평가액} - \text{최저보장가치의 현재가치(floor)}
\]

\[
\text{주식(위험자산) 투자금액} = \text{승수}(m) \times \text{쿠션}
\]

- 예: 평가액 100억, floor 현재가치 90억, 승수 3 → 쿠션 10억, 주식 **30억**, 채권 70억.
- 승수가 클수록 상승장 참여도는 높지만 급락 시 floor 하회 위험도 커진다.
- 시장 급락(갭 하락)·거래비용·잦은 리밸런싱이 현실적 한계.

| 비교 | 전술적 자산배분 | 보험자산배분 |
|---|---|---|
| 매매 방향 | 역투자(하락 시 매수) | 추세추종(하락 시 매도) |
| 위험허용도 | 일정 | 가치에 따라 변화 |

!!! warning "자주 나오는 함정"
    - 보험전략은 가격 하락 시 주식을 **판다**(위험자산 비중 축소). "하락 시 추가 매수"는 오답.
    - CPPI 쿠션은 floor의 **현재가치**를 뺀다(만기 금액 그대로 빼지 않음).

## 6. 주식 포트폴리오 운용전략 <span class="star s3">★★★</span> { #ch6 }

**출제 포인트:** 패시브·액티브·준액티브 운용의 특징 비교, 인덱스 구성방법, 가치/성장 스타일 특징이 매회 1문항 안팎 출제된다.

| 구분 | 패시브(인덱싱) | 준액티브(인핸스드 인덱스) | 액티브 |
|---|---|---|---|
| 목표 | 지수 수익률 복제 | 지수 + 소폭 초과수익 | 지수 대비 초과수익(알파) |
| 추적오차 | 매우 작음 | 작게 관리 | 큼 |
| 비용 | 낮음 | 중간 | 높음 |
| 전제 | 시장 효율적 | 부분적 비효율 | 비효율 존재 |

- 인덱스 펀드 구성방법: **완전복제법**(전 종목 편입, 추적오차 최소·비용 큼), **표본추출법**(대표 종목 일부), **최적화법**(추적오차 최소화를 목적함수로 계량 모형 사용).
- 액티브 운용 스타일
    - **가치투자**: 저PER·저PBR·고배당, 저평가 종목. 이익 성장보다 가격 매력에 초점.
    - **성장투자**: 높은 이익성장률, 고PER 감수. 이익 모멘텀이 꺾이면 하락 위험 큼.
    - 혼합(GARP 등), 시가총액 기준(대형주/중소형주) 스타일.
- 운용 방향: **하향식(Top-down)** 거시경제→산업→기업 / **상향식(Bottom-up)** 개별 종목 분석 우선.
- 스타일 분석: 수익률 기반 vs 보유종목 기반. 스타일 일관성 유지 여부 점검.

!!! warning "자주 나오는 함정"
    - 액티브 펀드의 **추적오차**(벤치마크 대비 능동위험)가 패시브보다 크다.
    - 완전복제법은 추적오차는 가장 작지만 **거래비용·관리비용이 가장 크다**.
    - 가치주 = 저PER, 성장주 = 고PER. 반대로 내는 보기 주의.

## 7. 주식 포트폴리오 구성의 실제 <span class="star s1">★</span> { #ch7 }

**출제 포인트:** 포트폴리오 조정 방법의 구분 정도가 가끔 출제된다.

- 구성 과정: 투자 유니버스 선정 → 모델 포트폴리오 → 실제 포트폴리오 구성 → 사후 조정.
- **리밸런싱**: 상황 변화로 달라진 자산 구성비를 **원래 비율로 되돌림**.
- **업그레이딩**: 기대수익 대비 위험이 더 나은 자산으로 **교체**해 포트폴리오 개선.
- 매매 시 거래비용(수수료·시장충격비용)을 함께 고려한다.
