## 1. 경제모형과 경제정책의 분석 ： IS - LM 모형 <span class="star s3">★★★</span> { #ch1 }

**출제 포인트:** 재정·통화정책 시 곡선 이동 방향과 소득·이자율 변화, 곡선 기울기에 따른 정책 효과 비교, 피구효과가 출제된다.

- **IS 곡선**: 재화시장 균형(투자 = 저축)을 만족하는 \((Y, r)\) 조합 → **우하향**.
- **LM 곡선**: 화폐시장 균형(화폐수요 = 화폐공급)을 만족하는 조합 → **우상향**.
- 교점에서 재화시장과 화폐시장이 동시에 균형.

| 정책 | 곡선 이동 | 소득 \(Y\) | 이자율 \(r\) |
|---|---|:---:|:---:|
| 확대 재정정책(정부지출↑, 감세) | IS 우측 | ↑ | ↑ |
| 긴축 재정정책 | IS 좌측 | ↓ | ↓ |
| 확대 통화정책(통화량↑) | LM 우측 | ↑ | ↓ |
| 긴축 통화정책 | LM 좌측 | ↓ | ↑ |

- **구축효과**: 확대 재정 → 이자율 상승 → 민간투자 감소로 효과 일부 상쇄.
- 정책 효과와 기울기

| 상황 | 재정정책 | 통화정책 |
|---|---|---|
| LM 수평(**유동성함정**) | 매우 효과적(구축효과 없음) | **무력** |
| LM 수직(고전학파) | **무력**(완전 구축) | 매우 효과적 |
| IS 수직(투자의 이자율 탄력성 0) | 매우 효과적 | 무력 |

- 투자의 이자율 탄력성이 클수록 IS가 완만 → 통화정책 효과 ↑, 재정정책 효과 ↓.
- 화폐수요의 이자율 탄력성이 클수록 LM이 완만 → 재정정책 효과 ↑.
- **피구효과(실질잔고효과)**: 물가 하락 → 실질 부(富) 증가 → 소비 증가 → IS 우측 이동. 유동성함정에서도 경기 회복 경로가 있다는 고전학파의 반론.
- 고전학파 화폐수량설: \( MV = PY \) (\(V\): 통화유통속도).

!!! warning "자주 나오는 함정"
    - 확대 통화정책은 이자율을 **낮춘다**. 확대 재정정책은 이자율을 **높인다**.
    - 유동성함정에서 무력한 것은 **통화정책**이다. 재정정책이 무력하다는 보기 주의.
    - 피구효과는 LM이 아니라 **IS 곡선**을 이동시킨다.

## 2. 이자율의 결정과 기간구조 <span class="star s2">★★</span> { #ch2 }

**출제 포인트:** 이자율 결정이론의 이름 매칭과 기간구조 이론별 수익률곡선 해석.

- 이자율 결정이론: **고전학파 대부자금설**(저축과 투자, 실물 측면) / **케인즈 유동성선호설**(화폐 수급, 화폐적 측면).
- **피셔방정식**: 명목이자율 \( i \approx r + \pi^e \) (실질이자율 + 기대인플레이션).
- 기간구조 이론

| 이론 | 핵심 | 수익률곡선 해석 |
|---|---|---|
| 불편기대이론 | 장기금리 = 미래 단기금리 기대의 평균 | 우상향 = 단기금리 상승 예상 |
| 유동성프리미엄이론(편중기대) | 기대 + 장기채 유동성 프리미엄 | 기대가 일정해도 우상향 |
| 시장분할이론 | 만기별 시장 분리, 각자 수급 | 만기 간 대체 없음 |
| 선호영역이론 | 선호 만기 있으나 프리미엄 주면 이동 | 분할 + 프리미엄 절충 |

- 내재 선도금리: \( (1+{}_0R_2)^2 = (1+{}_0R_1)(1+{}_1f_1) \)

!!! warning "자주 나오는 함정"
    - 불편기대이론은 장·단기채가 **완전 대체**된다고 본다. 시장분할이론은 대체되지 않는다고 본다.

## 3. 이자율의 변동요인 분석 <span class="star s1">★</span> { #ch3 }

**출제 포인트:** 통화량 증가가 이자율에 미치는 효과의 이름과 방향.

- 통화량 증가 시: **유동성효과**(단기, 이자율 ↓) → **소득효과**(소득 증가로 화폐수요↑, 이자율 ↑) → **피셔효과/기대인플레이션 효과**(이자율 ↑).
- 경기 확장 → 자금수요 증가 → 이자율 상승 압력. 물가 상승 기대 → 명목금리 상승.
- 통화유통속도 \( V = PY/M \): 화폐 1단위가 일정 기간 거래에 쓰인 횟수.

## 4. 경기변동과 경기예측 <span class="star s2">★★</span> { #ch4 }

**출제 포인트:** BSI 계산과 해석, 경기예측 방법의 종류가 출제된다.

- 경기순환: 확장(회복→호황) / 수축(후퇴→불황). 저점~정점 = 확장국면, 정점~저점 = 수축국면.
- 경기종합지수(CI): **선행·동행·후행** 지수로 구분. 전년동월비·순환변동치로 국면 판단.
- **BSI(기업경기실사지수)**

\[
\text{BSI} = \frac{\text{긍정 응답 업체 수} - \text{부정 응답 업체 수}}{\text{전체 응답 업체 수}} \times 100 + 100
\]

- 범위 **0~200**, **100 초과 = 확장**(긍정이 많음), 100 미만 = 수축. CSI(소비자동향지수)도 같은 해석.
- 경기예측 방법: 경제지표(경기종합지수 등) 분석, 설문조사(BSI·CSI), 계량경제모형, 시계열 모형.
- 고용지표: 경제활동참가율 = 경제활동인구 ÷ 15세 이상 인구, 실업률 = 실업자 ÷ 경제활동인구.

!!! warning "자주 나오는 함정"
    - BSI 100은 긍정·부정 응답이 **같다**는 의미. 경기 수준 자체가 아니라 **기업가의 판단 방향**을 나타낸다.
    - 실업률의 분모는 15세 이상 인구가 아니라 **경제활동인구**.
