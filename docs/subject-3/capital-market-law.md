## 1. 총설 <span class="star s1">★</span> { #ch1 }

**출제 포인트:** 자본시장법의 제정 취지(규제 패러다임 전환)를 묻는 개념 문제.

- 2009.2.4 시행. 증권거래법 등 6개 법률 통합.
- 4대 변화: **열거주의 → 포괄주의**, **기관별 → 기능별 규제**, 업무범위 확대(겸영 허용), 투자자보호 강화.
- 규제기관: 금융위원회(증권선물위원회), 금융감독원 / 자율규제: 한국거래소, 한국금융투자협회.

## 2. 금융투자상품 및 금융투자업 <span class="star s3">★★★</span> { #ch2 }

**출제 포인트:** 어떤 상품이 증권/파생상품/비금융투자상품인지, 어떤 투자자가 전문투자자인지 분류하는 문제가 매회 나온다.

- 금융투자상품 = 이익 목적 + 금전 등 지급 + **투자성(원본손실 가능성)**.
- **증권**: 원본까지만 손실(추가지급의무 없음) / **파생상품**: 원본 초과손실 가능.
- 명시적 제외: **원화표시 CD**, 관리형신탁의 수익권, 주식매수선택권(스톡옵션).

| 증권 6종 | 예시 |
|---|---|
| 채무증권 | 국채, 회사채, CP |
| 지분증권 | 주식, 출자지분 |
| 수익증권 | 투자신탁 수익증권 |
| 투자계약증권 | 공동사업 결과로 손익 귀속 |
| 파생결합증권 | ELS, DLS, ELW |
| 증권예탁증권 | DR |

- 파생상품: 선도·옵션·스왑 / 장내(거래소) vs 장외.
- 금융투자업 6종: **투자매매업, 투자중개업, 집합투자업, 투자자문업, 투자일임업, 신탁업**.
- 투자자 구분

| 구분 | 내용 |
|---|---|
| 절대적 전문투자자 | 국가, 한국은행, 금융기관 등 — 일반투자자로 전환 불가 |
| 상대적 전문투자자 | 주권상장법인, 지방자치단체 등 — 일반투자자 대우 요청 가능 |
| 자발적 전문투자자 | 일정 요건 개인·법인이 신청(금융투자상품 잔고 등 요건은 최신 기본서 확인) |
| 일반투자자 | 전문투자자가 아닌 투자자 |

- 주권상장법인은 **장외파생상품** 거래 시 별도 의사표시가 없으면 일반투자자로 본다.

!!! warning "자주 나오는 함정"
    - 원화표시 CD는 금융투자상품 아님(외화표시 CD와 구분).
    - ELW는 파생상품이 아니라 **파생결합증권(증권)**.
    - 지자체를 절대적 전문투자자로 내는 지문 → 상대적 전문투자자.

## 3. 금융투자업자에 대한 규제 · 감독 <span class="star s2">★★</span> { #ch3 }

**출제 포인트:** 인가 대상 vs 등록 대상 구분, 건전성 비율과 적기시정조치 기준.

- **인가**: 투자매매업, 투자중개업, 집합투자업, 신탁업 / **등록**: 투자자문업, 투자일임업, 일반 사모집합투자업, 온라인소액투자중개업.
- 진입요건은 인가가 등록보다 엄격, 진입 후에도 요건 **유지의무**.
- **순자본비율(NCR)** 기준 적기시정조치: **100% 미만 경영개선권고, 50% 미만 경영개선요구, 0% 미만 경영개선명령**.
- 자산건전성 5단계: 정상 – 요주의 – 고정 – 회수의문 – 추정손실.
- 대주주 등과의 거래 제한, 경영공시, 이해상충 관리·정보교류차단(내부통제기준으로 운영).

!!! warning "자주 나오는 함정"
    - 투자자문·일임업을 "인가" 대상으로 내는 지문 → 등록.

## 4. 투자매매업자 및 투자중개업자에 대한 영업행위규제 <span class="star s3">★★★</span> { #ch4 }

**출제 포인트:** 공통 영업행위 규칙(자기계약·최선집행·임의매매 등)과 불건전 영업행위의 예외, 투자권유 규제의 근거법(금소법) 구분.

- **매매형태 명시**: 주문 받기 전 자기가 투자매매업자인지 투자중개업자인지 밝힐 것.
- **자기계약 금지**: 같은 거래에서 본인이 상대방이 되는 것 금지(증권시장·파생상품시장을 통한 매매 등은 예외).
- **최선집행의무**: 최선집행기준 마련·공표, 정기 점검.
- **임의매매 금지**(투자자 지시 없이 매매) vs **일임매매**(투자일임업 형태로만 가능).
- 불건전 영업행위
    - **선행매매**(front-running) 금지
    - **조사분석자료 공표 후 24시간 경과 전** 자기계산 매매 금지
    - 조사분석자료 작성자에게 기업금융업무와 연동된 성과보수 지급 금지
    - 투자권유대행인·투자권유자문인력이 아닌 자에게 투자권유 위탁 금지
- **신용공여**: 투자매매·중개업자가 증권 매수자금 융자·대주. 담보비율 등 세부는 금융투자업규정·협회규정(최신 기본서 확인).
- **투자자예탁금**은 고유재산과 구분하여 **증권금융회사**에 예치, 상계·압류 금지.
- 투자권유 규제: 2021.3.25 이후 적합성·적정성·설명의무·부당권유 금지 등은 **금융소비자보호법**이 근거. 투자권유준칙 제정·공시는 자본시장법에 남아 있음.

!!! warning "자주 나오는 함정"
    - "증권시장을 통한 매매도 자기계약 금지" → 예외로 허용.
    - 적합성·설명의무의 근거를 자본시장법으로 내는 지문 → 2021년 이후 금소법.

## 5. 집합투자업자의 영업행위 규칙 <span class="star s3">★★★</span> { #ch5 }

**출제 포인트:** 공모펀드 자산운용 제한의 비율 숫자가 거의 매회 나온다.

| 운용 제한 (공모 기준) | 한도 |
|---|---|
| 동일종목 증권 | 각 펀드 자산총액의 **10%** 이내 (국채 등은 100%, 지방채·특수채 등은 30%) |
| 동일법인 발행 지분증권 | 각 펀드 **10%**, 동일 운용사의 전 펀드 합산 **20%** 이내 |
| 파생상품 위험평가액 | 펀드 **순자산의 100%** 이내 |
| 동일 거래상대방 장외파생 위험평가액 | 자산총액의 **10%** 이내 |
| 동일 운용사 집합투자증권 투자 | 자산총액의 **50%** 이내 |
| 동일 펀드 집합투자증권 투자 | 자산총액의 **20%** 이내 |

- **금전차입·대여 원칙적 금지** (대량환매 등 예외적 차입은 순자산의 10% 이내).
- 자기 집합투자증권 취득 금지(예외: 환매청구 대응 등), 이해관계인과의 거래 제한.
- 불건전 영업행위: 선행매매, 특정 자산 교차투자, 투자운용인력이 아닌 자의 운용 등 금지.
- 의결권: 원칙적으로 충실히 행사, 일정 경우 **중립투표(Shadow voting)**. 투자한도 초과 취득 주식은 의결권 행사 불가.
- **자산운용보고서**: **3개월마다 1회 이상** 투자자에게 교부.
- 성과보수는 원칙적으로 제한(공모펀드는 요건 충족 시 허용).

!!! warning "자주 나오는 함정"
    - 동일법인 지분증권 "전 펀드 합산 10%" → 20%.
    - 파생상품 위험평가액 기준을 "자산총액"으로 → 순자산.

## 6. 투자자문업자 및 투자일임업자의 영업행위 규칙 <span class="star s1">★</span> { #ch6 }

**출제 포인트:** 불건전 영업행위 금지 목록에서 1문제 정도.

- 투자자로부터 **금전·증권 보관·예탁 금지**, 투자자에게 금전·증권 **대여 금지**.
- 계약 체결 시 서면자료 교부, 투자일임보고서는 **3개월마다 1회 이상** 교부.
- 투자일임재산으로 자기·관계인 발행 증권 취득, 과당매매 등 금지.
- 유사투자자문업은 신고제(불특정 다수 대상). 양방향 소통 리딩방 규제 강화(최신 기본서 확인).

## 7. 신탁업자의 영업행위 규칙 <span class="star s1">★</span> { #ch7 }

**출제 포인트:** 수탁 가능 재산과 손실보전 금지 원칙.

- 수탁 가능 재산: 금전, 증권, 금전채권, 동산, 부동산, 부동산 관련 권리, 무체재산권.
- 신탁재산과 고유재산의 **구분관리**, 원칙적으로 상호 거래 금지.
- **손실보전·이익보장 금지**(연금신탁 등 법정 예외).
- 신탁재산 운용 내역 정기 통지, 수익자 보호의무.

## 8. 증권 발행시장 공시제도 <span class="star s2">★★</span> { #ch8 }

**출제 포인트:** 모집·매출 정의, 증권신고서 제출 기준, 투자설명서 종류.

- **모집**: **50인 이상**에게 새로 발행되는 증권의 취득 청약 권유 / **매출**: 이미 발행된 증권의 매도·매수 청약 권유(50인 이상).
- 50인 산정 시 **과거 6개월** 내 같은 종류 증권 권유 인원 합산. 전문투자자 등은 제외.
- 50인 미만이라도 **전매가능성**이 있으면 모집으로 간주.
- **증권신고서**: 모집·매출 가액 **10억원 이상**(과거 1년 합산) 시 금융위에 제출. 10억 미만은 소액공모 공시.
- 신고서 수리 후 일정 기간 경과해야 효력 발생(증권 종류별 기간은 최신 기본서 확인), 효력 발생 전 청약 승낙 불가.
- 투자설명서: **(정식)투자설명서, 예비투자설명서**(효력 발생 전), **간이투자설명서**.
- 일괄신고서, 정정신고서 제도.

!!! warning "자주 나오는 함정"
    - 효력 발생은 정부가 증권 가치를 보증하는 것이 아님.

## 9. 증권 유통시장 공시제도 <span class="star s2">★★</span> { #ch9 }

**출제 포인트:** 정기공시 제출기한 숫자와 공시 종류 구분.

| 공시 | 기한 |
|---|---|
| 사업보고서 | 사업연도 경과 후 **90일** 이내 |
| 반기·분기보고서 | 기간 경과 후 **45일** 이내 |
| 주요사항보고서 | 사유 발생 다음 날까지(일부 사유는 기한 상이, 최신 기본서 확인) |

- 주요사항보고서 사유: 부도, 영업정지, 회생절차 개시, 합병·분할, 자기주식 취득·처분 결정 등.
- **수시공시**(거래소 규정): 주요경영사항 공시, **조회공시**(풍문 등에 대한 거래소 요구), **공정공시**(미공개정보를 특정인에게 제공 시 모두에게 공시).
- 공시 위반 시 손해배상책임, 과징금.

## 10. 기업의 인수합병(M&A) 관련 제도 <span class="star s2">★★</span> { #ch10 }

**출제 포인트:** 공개매수 의무 요건과 5% 대량보유보고 숫자.

- **공개매수 의무**: 과거 **6개월** 동안 증권시장 밖에서 **10인 이상**으로부터 매수 등을 하여 본인·특별관계자 보유 비율이 **5% 이상**이 되는 경우.
- 공개매수기간 **20일 이상 60일 이내**. 공개매수자는 원칙적으로 철회 제한, **응모주주는 언제든 철회 가능**.
- 공개매수 기간 중 공개매수 외 별도 매수 금지, 응모 초과 시 **안분비례** 매수.
- **5% 대량보유보고(5% Rule)**: 주권상장법인 주식 등을 **5% 이상** 보유하게 되면 **5일 이내** 보고, 이후 **1% 이상** 변동 시 변동보고, 보유목적 변경 시 보고.
- 경영참가 목적 보고자는 **냉각기간**(보고 사유 발생일부터 보고 후 5일까지) 추가 취득·의결권 행사 금지.
- 단순투자·일반투자 목적은 약식·완화된 보고기한 적용(세부 기한은 최신 기본서 확인).
- 의결권 대리행사 권유: 위임장 용지·참고서류를 금융위·거래소에 제출, 권유 대상자에게 교부.

!!! warning "자주 나오는 함정"
    - 공개매수 요건 "장내 매수 포함" → 증권시장 **밖** 매수.
    - "응모주주는 철회 불가" → 언제든 철회 가능.

## 11. 집합투자기구(총칙) <span class="star s2">★★</span> { #ch11 }

**출제 포인트:** 집합투자 정의 요소와 기구 형태별 특징, 수익자총회 결의 요건.

- 집합투자 = **2인 이상** 투자자로부터 모은 금전 등을 투자자의 **일상적 운용지시 없이** 운용하고 결과를 투자자에게 귀속.
- 형태: **투자신탁**(신탁형), 투자회사·투자유한회사·투자합자회사·투자유한책임회사(회사형), 투자합자조합·투자익명조합(조합형).
- 투자신탁 관계자: 집합투자업자(위탁자), 신탁업자(수탁자), 수익자.
- 집합투자기구는 금융위에 **등록**.
- **수익자총회**: 집합투자업자 소집(수탁자, 발행 수익증권 **5% 이상** 보유 수익자도 소집 요구 가능).
    - 법정 결의사항: 출석 수익자 의결권 **과반수** + 발행 총좌수의 **1/4 이상**
    - 연기수익자총회: 출석 과반수 + 총좌수 **1/8 이상**
- 결의 반대 수익자는 **수익증권매수청구권** 행사 가능.

!!! warning "자주 나오는 함정"
    - 투자회사의 법인이사는 집합투자업자(1인), 감독이사는 2인 이상 — 세부 구성은 최신 기본서 확인.

## 12. 집합투자기구의 구성 등 <span class="star s3">★★★</span> { #ch12 }

**출제 포인트:** 환매·기준가격·평가 원칙과 특수 집합투자기구·사모펀드 구분이 자주 나온다.

- **환매**: 투자자는 언제든 환매청구 가능(환매금지형 제외). 환매대금은 청구일로부터 **15일 이내**에서 규약으로 정한 날에 지급.
- **미래가격(Forward pricing)** 원칙: 환매청구일 **이후** 산정되는 기준가격 적용.
- **환매연기**: 집합투자재산 처분 불가 등 사유 시 연기, **6주 이내** 집합투자자총회에서 처리 방안 결의.
- 기준가격 공고·게시, 변경 시 사유 공시.
- **집합투자재산 평가**: 원칙 **시가**, 시가가 없으면 **공정가액**(집합투자재산평가위원회). MMF는 장부가 평가 허용.
- 결산 시 회계감사 의무(일정 규모 이하 면제, 기준은 최신 기본서 확인).

| 특수 집합투자기구 | 핵심 |
|---|---|
| 환매금지형 | 존속기간 정한 펀드. 부동산·특별자산 등 시장성 없는 자산 펀드는 의무. 집합투자증권 상장(설정일부터 90일 이내) |
| 종류형 | 판매보수 등 클래스만 다름, 운용은 통합 |
| 전환형 | 다른 펀드로 전환 가능 |
| 모자형 | 자펀드는 모펀드에만 투자 |
| 상장지수(ETF) | 지수 추종, 상장, 일부 운용제한 완화 |

- **사모집합투자기구(2021.10 개편)**: **일반 사모집합투자기구** / **기관전용 사모집합투자기구**. 투자자 총수 **100인 이하**(일반투자자는 49인 이하).

!!! warning "자주 나오는 함정"
    - 환매 시 "청구일 당일 기준가격" → 원칙은 미래가격.
    - 종류형을 "클래스별로 따로 운용"으로 → 운용은 하나.

## 13. 집합투자기구 관련 금융위원회 규정 <span class="star s2">★★</span> { #ch13 }

**출제 포인트:** 금융투자업규정상 집합투자 세부 기준(파생상품 위험평가액 산정, MMF·장외파생 거래상대방 요건 등).

- 근거: 금융투자업규정(금융위 고시) — 시행령의 위임 사항을 구체화.
- 파생상품 **위험평가액**: 명목계약금액 기준으로 산정(옵션은 델타 등 반영).
- 장외파생상품 거래상대방: 적격 요건(신용등급 등)을 갖춘 자로 제한.
- **MMF**: 편입자산 신용등급·잔존만기·분산 요건이 엄격(세부 수치는 최신 기본서 확인), 장부가 평가.
- 집합투자재산 평가·기준가격 산정 오류 시 조치, 공시 기준.
- 펀드 판매 관련: 판매보수·수수료 한도(최신 기본서 확인), 이익 제공 금지.
- 세부 수치는 개정이 잦은 영역이므로 숫자보다 **"누가 정하는가(법·시행령·규정)"** 와 개념 구분을 우선한다.

## 14. 장외거래 및 주식 소유제한 <span class="star s1">★</span> { #ch14 }

- 일반투자자와 장외파생상품 거래는 **위험회피 목적**인 경우에 한함.

## 15. 불공정거래행위에 대한 규제 <span class="star s3">★★★</span> { #ch15 }

**출제 포인트:** 내부자 범위, 단기매매차익 반환, 시세조종 유형, 시장질서 교란행위와의 차이를 묻는다.

- **미공개중요정보 이용 금지(제174조)**
    - 규제 대상: 내부자(회사·임직원·대리인·**주요주주**), 준내부자(인허가권자·계약체결자 등), 이들로부터 정보를 받은 **1차 정보수령자**.
    - 내부자 지위 종료 후 **1년** 이내인 자도 포함.
    - 정보 공개 후 일정 시간 경과 전까지는 미공개로 봄(매체별 시간은 최신 기본서 확인).
- **주요주주**: 의결권 있는 발행주식 **10% 이상** 보유 또는 사실상 영향력 행사자.
- **단기매매차익 반환**: 주권상장법인 임원·(일부)직원·주요주주가 **6개월** 이내 매수→매도(매도→매수)로 얻은 이익은 회사에 반환.
- **임원·주요주주 소유상황 보고**: 특정증권 등 소유 및 변동 시 **5일 이내** 보고.
- **시세조종(제176조)**: 위장거래(통정매매·가장매매), 현실거래, 허위표시, 가격고정·안정조작(안정조작·시장조성은 예외 허용), 연계 시세조종.
- **부정거래(제178조)**: 부정한 수단·계획·기교, 풍문 유포, 위계 사용 등 포괄 규정.
- **시장질서 교란행위(제178조의2)**: **목적성 불요**, **2차 이상 정보수령자**까지 포함, 형사처벌이 아닌 **과징금** 부과.
- 제재: 형사처벌 + 손해배상. 2024년 개정으로 불공정거래에 **과징금** 도입·벌금 상향(금액 기준은 최신 기본서 확인).

!!! warning "자주 나오는 함정"
    - 미공개정보 이용 금지는 1차 수령자까지, 교란행위는 2차 이상까지.
    - 단기매매차익은 "1년" → **6개월**.
    - 시세조종·미공개정보는 형사처벌, 시장질서 교란행위는 과징금.
