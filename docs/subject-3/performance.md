## 1. 서론 <span class="star s1">★</span> { #ch1 }

**출제 포인트:** 성과평가의 목적과 평가 대상 구분이 가끔 출제된다.

- 투자자 관점 **펀드 평가**(투자할 펀드 선택)와 **운용자·운용회사 평가**(운용 능력 판단)를 구분.
- 성과평가는 사후적 평가로, 다음 투자관리 과정(계획)에 피드백된다.
- 운용 성과는 운용자 능력뿐 아니라 운이나 시장 상황의 영향도 받으므로 위험을 함께 고려해야 한다.

## 2. 성과평가 기초사항 <span class="star s3">★★★</span> { #ch2 }

**출제 포인트:** 시간가중수익률과 금액가중수익률 중 어느 쪽이 운용자 평가에 적합한지, 간단한 수익률 계산이 매회 출제된다.

| 구분 | 시간가중수익률(TWR) | 금액가중수익률(MWR) |
|---|---|---|
| 개념 | 기간별 수익률을 기하적으로 연결 | 현금흐름의 현재가치를 일치시키는 **내부수익률(IRR)** |
| 현금 유출입 영향 | **제거** | 반영 |
| 적합한 평가 | **운용자(펀드매니저) 능력 평가** | 투자자 입장의 실제 성과 |

- 시간가중수익률: \( R_{TW} = (1+R_1)(1+R_2)\cdots(1+R_n) - 1 \)
- 금액가중수익률: \( \sum_t \dfrac{CF_t}{(1+R_{MW})^t} = 0 \) 을 만족하는 \(R_{MW}\).
- 산술평균수익률 ≥ 기하평균수익률 (변동성이 클수록 차이 확대). 다기간 실제 누적 성과는 기하평균이 정확.
- 예: 1년차 +100%, 2년차 −50% → 산술평균 **25%**, 기하평균 **0%**.
- 위험 측정: 표준편차(총위험), 베타(체계적 위험), 추적오차(기준지표 대비 초과수익의 표준편차), 하락위험 지표.

!!! warning "자주 나오는 함정"
    - 운용자는 투자자의 자금 유출입 시점을 통제할 수 없으므로 운용자 평가는 **시간가중수익률**.
    - 금액가중수익률은 투자금 유출입 시점에 따라 성과가 달라진다.

## 3. 기준 지표 <span class="star s2">★★</span> { #ch3 }

**출제 포인트:** 바람직한 기준지표의 요건과 기준지표 종류를 고르는 문제.

- 바람직한 기준지표의 요건: **명확성**(구성종목·비중이 명확), **투자 가능성**, **측정 가능성**, **적합성**(운용 스타일과 부합), 현재 투자견해 반영, **사전에 정의**될 것.
- 종류: 시장지수, 섹터·스타일 지수, **정상 포트폴리오**(normal portfolio, 운용자의 평소 투자 대상 종목군), 맞춤형 지수.
- 동류집단(peer group) 비교: 이해하기 쉬우나 **생존 편의(survivorship bias)**, 집단 구성 기준 차이 문제.

!!! warning "자주 나오는 함정"
    - 기준지표는 운용 **이후에** 정하는 것이 아니라 **사전에** 정한다.

## 4. 위험조정 성과지표 <span class="star s3">★★★</span> { #ch4 }

**출제 포인트:** 네 지표의 공식 계산과 "어떤 위험을 쓰는가"에 따른 특징 비교가 매회 출제된다.

| 지표 | 공식 | 위험 척도 | 기반 |
|---|---|---|---|
| 샤프비율 | \( \dfrac{R_p - R_f}{\sigma_p} \) | 총위험(표준편차) | CML |
| 트레이너비율 | \( \dfrac{R_p - R_f}{\beta_p} \) | 체계적 위험(베타) | SML |
| 젠센 알파 | \( R_p - [R_f + \beta_p(R_m - R_f)] \) | 체계적 위험(베타) | SML(CAPM) |
| 정보비율 | \( \dfrac{R_p - R_B}{\text{추적오차}} \) | 추적오차 \(\sigma(R_p - R_B)\)(능동위험) | 기준지표 대비 |

- **샤프비율**: 총위험 1단위당 초과수익. 투자자의 자산 대부분이 해당 펀드인 경우(분산이 덜 된 포트폴리오) 평가에 적합.
- **트레이너비율**: 체계적 위험 1단위당 초과수익. **충분히 분산된** 포트폴리오 평가에 적합.
- **젠센 알파**: CAPM 기대수익을 초과한 수익률. 알파 > 0이면 우월한 성과. 단, 베타가 다른 펀드 간 **순위 비교**에는 한계.
- **정보비율**: 추적오차 1단위당 기준지표 초과수익(적극적 운용 능력). 값이 클수록 운용 능력 우수. 평가기간이 짧으면 신뢰도 낮음.
- 예: \( R_p=12\%, R_f=4\%, \sigma_p=20\%, \beta_p=0.8 \) → 샤프 **0.4**, 트레이너 **0.1**(10%p).
- 기본서에는 이 밖에 하락위험 기반 지표 등도 다루므로 범위를 확인할 것 (최신 기본서 확인).

!!! warning "자주 나오는 함정"
    - 샤프는 **표준편차**, 트레이너·젠센은 **베타**. 분모 바꿔 낸 보기 주의.
    - 정보비율의 기준은 무위험수익률이 아니라 **기준지표 수익률**.
    - 잘 분산된 포트폴리오면 샤프와 트레이너의 순위가 비슷해진다.

## 5. 성과 특성 분석 <span class="star s2">★★</span> { #ch5 }

**출제 포인트:** 성과요인을 자산배분 효과와 종목선택 효과로 나누는 개념, 스타일 분석 방법 구분.

- **성과요인 분해**: 초과성과 = **자산배분(시점선택) 효과** + **증권(종목)선택 효과** (+ 상호작용).
- **스타일 분석**: **수익률 기반**(펀드 수익률을 스타일 지수에 회귀, 자료 구하기 쉬움) vs **보유종목 기반**(실제 보유 종목 분석, 정확하나 자료 부담).
- 시장예측(타이밍) 능력 측정 모형(예: 트레이너-마주이, 헨릭슨-머튼)은 기본서 수록 범위를 확인할 것 (최신 기본서 확인).
- 운용 스타일이 기준지표와 다르면 성과평가가 왜곡될 수 있다.

## 6. 성과 발표 방법 <span class="star s1">★</span> { #ch6 }

**출제 포인트:** GIPS의 기본 원칙 정도가 지엽적으로 나온다.

- **GIPS**(글로벌 투자성과 기준): 운용회사 성과를 공정하게 비교·발표하기 위한 국제 기준.
- 운용회사(firm) 전체 단위로 준수. 유사한 전략의 포트폴리오를 묶은 **복합포트폴리오(composite)** 단위로 발표, 성과 좋은 포트폴리오만 골라 발표(체리피킹) 금지.
- 수익률은 시간가중수익률 원칙. 최소 발표 기간 등 세부 요건은 기본서 확인 (최신 기본서 확인).
