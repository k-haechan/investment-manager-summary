    기출복원에서 **스트래들·스트랭글·불 스프레드·방어적 풋**과 **풋-콜 패리티·옵션 가격 계산**이 회차마다 나온다. 합성전략 손익구조 그림 → 풋-콜 패리티 → 그릭스 부호 → 선물 보유비용모형 순으로 공부한다.
    개념을 확실히 잡으면 계산을 놓쳐도 개념 문제로 점수를 지킬 수 있다.

## 1. 파생상품 개요 <span class="star s1">★</span> { #ch1 }

**출제 포인트:** 파생상품의 경제적 기능을 고르는 단순 개념 문제.

- 기능: **위험 전가(헤지)**, **가격 발견**, 거래비용 절감, 시장 효율성 제고, 새로운 투자수단 제공.
- 장내(거래소, 표준화) vs 장외(맞춤형, 상대방 신용위험).
- 기초자산: 주식·주가지수·금리·통화·상품·신용 등.

## 2. 선도거래와 선물거래의 기본 메커니즘 <span class="star s1">★</span> { #ch2 }

**출제 포인트:** 선도와 선물의 차이 비교.

| 구분 | 선도(Forward) | 선물(Futures) |
|---|---|---|
| 거래장소 | 장외 | 거래소 |
| 계약조건 | 당사자 합의(비표준) | 표준화 |
| 정산 | 만기 1회 | **일일정산** |
| 신용위험 | 상대방 위험 존재 | 청산소가 보증, 증거금 |
| 만기 전 청산 | 어려움 | 반대매매로 쉬움 |

- 증거금: 개시증거금, 유지증거금 아래로 떨어지면 **추가증거금(마진콜)** 납부.

## 3. 선물 총론 <span class="star s2">★★</span> { #ch3 }

**출제 포인트:** 백워데이션·콘탱고 정의, 이론가격 계산, 차익거래 방향, 헤지 계약수 계산.

- 보유비용모형(주가지수선물, 단리 근사): \( F = S\left[1 + (r - d)\times \dfrac{T}{365}\right] \) (\(d\): 배당수익률)
- **콘탱고**: 선물가격 > 현물가격(정상시장). **백워데이션**: 선물가격 < 현물가격(역조시장).
- 베이시스 = 선물가격 − 현물가격 (교재에 따라 현물 − 선물로 정의하기도 함, 최신 기본서 확인). 만기에 0으로 수렴.
- 차익거래
    - 선물 **고평가**(시장가 > 이론가) → **매수차익거래**: 현물 매수 + 선물 매도.
    - 선물 **저평가** → **매도차익거래**: 현물 매도 + 선물 매수.
- 헤지 계약수(주가지수선물): \( N = \beta \times \dfrac{\text{포트폴리오 가치}}{\text{선물가격} \times \text{거래승수}} \)
- 최소분산 헤지비율: \( h = \rho \dfrac{\sigma_S}{\sigma_F} \)
- 보유 주식 하락 위험 → 선물 **매도헤지**, 향후 매입 예정 → **매수헤지**.

!!! warning "자주 나오는 함정"
    - 백워데이션을 "선물가격이 현물보다 높은 상태"로 내는 보기 → 틀림(그건 콘탱고).
    - 선물 고평가 시 선물을 **매도**한다.

## 4. 옵션 기초 <span class="star s2">★★</span> { #ch4 }

**출제 포인트:** 내재가치·시간가치 계산, 내가격/외가격 판단, 매수·매도자의 권리와 의무.

- 콜: 살 권리 / 풋: 팔 권리. 매수자는 프리미엄 지급(손실 한정), 매도자는 프리미엄 수취(의무, 손실 큼).
- 내재가치: 콜 \( \max(S-K, 0) \), 풋 \( \max(K-S, 0) \). **시간가치 = 프리미엄 − 내재가치**, ATM에서 최대, 만기에 0.
- 콜: \(S>K\) 내가격(ITM), \(S=K\) 등가격(ATM), \(S<K\) 외가격(OTM). 풋은 반대.
- 유럽형(만기일에만 행사) vs 미국형(만기 전 언제든 행사).
- 만기 손익(프리미엄 \(c\)): 콜 매수 = \( \max(S_T-K,0) - c \), 손익분기점 \( K + c \). 풋 매수 손익분기점 \( K - p \).

## 5. 옵션을 이용한 합성전략 <span class="star s3">★★★</span> { #ch5 }

**출제 포인트:** 시장 전망에 맞는 전략 고르기, 스트래들·스트랭글 손익분기점 계산, 스프레드 최대 이익·손실 계산이 반복 출제된다.

| 전략 | 구성 | 전망 | 최대 이익 / 손실 |
|---|---|---|---|
| 강세 콜 스프레드 | 낮은 \(K_1\) 콜 매수 + 높은 \(K_2\) 콜 매도 | 완만한 상승 | 이익 \( (K_2-K_1) - \) 순프리미엄 / 손실 순프리미엄 |
| 강세 풋 스프레드 | 낮은 \(K_1\) 풋 매수 + 높은 \(K_2\) 풋 매도 | 완만한 상승 | 순프리미엄 수취가 최대 이익 |
| 약세 스프레드 | 높은 \(K\) 매수 + 낮은 \(K\) 매도 (콜 또는 풋) | 완만한 하락 | 이익·손실 모두 제한 |
| 스트래들 매수 | 같은 \(K\) 콜 매수 + 풋 매수 | 큰 변동(방향 무관) | 이익 무제한 / 손실 = 총 프리미엄 |
| 스트랭글 매수 | 외가격 풋 매수 + 외가격 콜 매수 | 큰 변동 | 스트래들보다 싸고 BEP 더 멂 |
| 스트래들·스트랭글 매도 | 위의 반대 | 횡보 | 이익 = 프리미엄 / 손실 무제한 |
| 나비형 매수 | \(K_1\) 콜 매수, \(K_2\) 콜 2개 매도, \(K_3\) 콜 매수 | 횡보 | 이익·손실 제한 |
| 커버드콜 | 주식 보유 + 콜 매도 | 횡보·약보합 | 상승 이익 제한 |
| 방어적 풋 | 주식 보유 + 풋 매수 | 하락 위험 방어 | 손실 하한 확보(보험) |
| 칼라 | 주식 + 풋 매수 + 콜 매도 | 비용 줄인 보험 | 상·하한 모두 제한 |

- 스트래들 매수 손익분기점: \( K \pm (c + p) \)
- 스트랭글 매수 손익분기점: \( K_{put} - (c+p) \), \( K_{call} + (c+p) \)
- 강세 콜 스프레드 손익분기점: \( K_1 + \) 순프리미엄.
- 스프레드 = 같은 종류 옵션의 매수·매도 조합(수직: 행사가 다름, 수평: 만기 다름).

!!! warning "자주 나오는 함정"
    - 스트래들·스트랭글 **매수**는 변동성 확대에 베팅, **매도**는 변동성 축소(횡보)에 베팅.
    - 강세 풋 스프레드는 초기에 프리미엄을 **받는다**(credit spread), 강세 콜 스프레드는 **낸다**(debit spread).
    - 방어적 풋 = 주식 + 풋 매수 → 손익구조가 **콜 매수**와 같다(풋-콜 패리티).

## 6. 옵션 프리미엄과 풋-콜 패리티 <span class="star s3">★★★</span> { #ch6 }

**출제 포인트:** 가격 결정요인이 콜·풋에 미치는 방향, 풋-콜 패리티로 콜(풋) 가격 계산, 합성 포지션 구성 문제.

- 옵션 가격 결정요인(다른 조건 일정)

| 요인 ↑ | 콜 | 풋 |
|---|:---:|:---:|
| 기초자산 가격 \(S\) | ↑ | ↓ |
| 행사가격 \(K\) | ↓ | ↑ |
| 변동성 \(\sigma\) | ↑ | ↑ |
| 잔존기간 \(T\) | ↑ | ↑ (유럽형 풋은 예외 가능) |
| 무위험이자율 \(r\) | ↑ | ↓ |
| 배당 | ↓ | ↑ |

- **풋-콜 패리티**(유럽형, 같은 기초자산·행사가·만기, 무배당)

\[
c + \frac{K}{(1+r)^T} = p + S \qquad\Longleftrightarrow\qquad c - p = S - \frac{K}{(1+r)^T}
\]

- (연속복리로는 \( c + Ke^{-rT} = p + S \). 문제에 주어진 할인 방식을 따른다.)
- 합성 포지션(위 식의 변형)

| 합성 대상 | 구성 |
|---|---|
| 합성 콜 매수 | 주식 매수 + 풋 매수 − 채권(\(K\) 현재가치 차입) |
| 합성 풋 매수 | 콜 매수 + 채권 매수 − 주식(공매도) |
| 합성 주식 매수(선물 매수) | 콜 매수 + 풋 매도 (+ 채권) |
| 합성 무위험채권 | 주식 매수 + 풋 매수 + 콜 매도 (컨버전) |

- 등식이 깨지면 차익거래: 상대적으로 비싼 쪽 매도 + 싼 쪽 매수(컨버전 / 리버설).

!!! warning "자주 나오는 함정"
    - 변동성 상승은 콜·풋 **모두** 가격을 올린다.
    - 이자율 상승은 콜 ↑, 풋 ↓ (행사가 현재가치가 낮아지므로).
    - 풋-콜 패리티는 **유럽형** 옵션 기준.

## 7. 옵션 가격결정 <span class="star s2">★★</span> { #ch7 }

**출제 포인트:** 1기간 이항모형의 위험중립확률 계산, 블랙-숄즈 식의 구성요소 이해.

- 1기간 이항모형(상승배수 \(u\), 하락배수 \(d\), 기간 무위험이자율 \(r\))

\[
p = \frac{(1+r) - d}{u - d}, \qquad c = \frac{p\,c_u + (1-p)\,c_d}{1+r}
\]

- 위험중립 확률은 실제 확률이 아니며, 투자자의 위험선호와 무관하게 가격이 결정된다.
- 블랙-숄즈(무배당 유럽형 콜)

\[
c = S\,N(d_1) - Ke^{-rT}N(d_2)
\]

\[
d_1 = \frac{\ln(S/K) + (r + \sigma^2/2)T}{\sigma\sqrt{T}}, \qquad d_2 = d_1 - \sigma\sqrt{T}
\]

- \(N(d_1)\) = 콜옵션의 **델타**, \(N(d_2)\) = 위험중립 세계에서 만기에 내가격으로 끝날 확률.
- 블랙-숄즈 가정: 기초자산 수익률 로그정규분포, 변동성·이자율 일정, 거래비용·세금 없음, 연속거래 가능.

## 8. 옵션 및 옵션 합성 포지션의 분석 <span class="star s2">★★</span> { #ch8 }

**출제 포인트:** 그릭스의 정의와 포지션별 부호(델타·감마·세타·로)가 기출에 나온다.

| 지표 | 의미 | 콜 매수 | 풋 매수 |
|---|---|:---:|:---:|
| 델타 | 기초자산 가격 변화에 대한 옵션가격 변화 | + (0~1) | − (−1~0) |
| 감마 | 기초자산 가격 변화에 대한 델타 변화 | + | + |
| 세타 | 시간 경과에 따른 옵션가격 변화 | − (대체로) | − (대체로) |
| 베가 | 변동성 변화에 대한 옵션가격 변화 | + | + |
| 로 | 이자율 변화에 대한 옵션가격 변화 | + | − |

- 매도 포지션은 부호가 반대. 감마·세타는 **ATM·만기 근접**일 때 절댓값이 가장 크다.
- 스트래들 매수: 델타 ≈ 0, 감마 +, 세타 −, 베가 +.
- 델타중립 헤지: 포지션 델타 합이 0이 되도록 기초자산 수량 조절, 감마가 클수록 재조정 자주 필요.

!!! warning "자주 나오는 함정"
    - 옵션 **매수** 포지션은 감마 +, 세타 − (시간이 지날수록 손해).
    - 풋 매수의 로는 **음(−)**.
