## 1. 국세기본법 <span class="star s3">★★★</span> { #ch1 }

**출제 포인트:** 송달 효력 시점, 기한 특례, 납세의무 성립 시기·확정 방식, 제척기간·소멸시효 연수를 "옳지 않은 것" 형태로 묻는다.

- **서류의 송달**: 교부·우편·전자송달이 원칙이고, 주소 불명 등일 때 공시송달을 한다.
    - 송달 효력은 도달주의가 원칙. 전자송달은 국세정보통신망에 저장된 때(또는 전자우편 주소에 입력된 때) 도달한 것으로 본다.
    - 공시송달은 공고한 날부터 **14일**이 지나면 송달된 것으로 본다.
- **기간과 기한**: 기한이 공휴일·토요일·근로자의 날이면 그 **다음 날**이 기한. 우편으로 낸 신고서는 통신날짜도장이 찍힌 날에 신고된 것으로 본다(발신주의).
- **납세의무의 성립 시기**

| 세목 | 성립 시기 |
|---|---|
| 소득세·법인세 | 과세기간이 끝나는 때 |
| 상속세 | 상속이 개시되는 때 |
| 증여세 | 증여재산을 취득하는 때 |
| 증권거래세 | 매매거래가 확정되는 때 |
| 원천징수하는 소득세·법인세 | 소득금액·수입금액을 지급하는 때 |

- **확정 방식**: 신고납세(소득세·법인세·부가가치세·증권거래세 등, 신고로 확정) / 부과과세(상속세·증여세, 정부 결정으로 확정) / 자동확정(인지세, 원천징수 소득세·법인세, 중간예납 법인세 등).
- **납부의무 소멸 사유**: 납부·충당, 부과 취소, 제척기간 만료, 징수권 소멸시효 완성.
- **제척기간**(일반 세목): 일반 **5년**, 무신고 **7년**, 사기 등 부정행위 **10년**. 상속·증여세는 **10년**(무신고·부정행위 등 **15년**).
- **소멸시효**: 5억원 이상 국세 **10년**, 5억원 미만 **5년**.
- **수정신고·경정청구·기한후신고**
    - 수정신고: 과소신고한 경우. 법정신고기한 후 2년 이내에 하면 과소신고가산세를 기간별로 감면한다.
    - 경정청구: 과다신고한 경우. 법정신고기한 후 **5년** 이내에 청구한다.
    - 기한후신고: 무신고한 경우. 관할 세무서장이 결정해 통지하기 전까지 할 수 있다.
- **제2차 납세의무자**: 청산인 등, 출자자, 법인, 사업양수인.

!!! warning "자주 나오는 함정"
    - 공시송달 효력은 "공고한 날"이 아니라 공고 후 **14일 경과** 시점부터 생긴다.
    - 상속세·증여세는 **부과과세** 세목이라 신고만으로는 세액이 확정되지 않는다(신고는 협력의무).
    - 경정청구는 세금을 **덜 내려는** 쪽(과다신고 시정), 수정신고는 **더 내는** 쪽(과소신고 시정)이다.

## 2. 소득세법 <span class="star s2">★★</span> { #ch2 }

**출제 포인트:** 거주자 판정, 과세기간·납세지, 종합·분류과세 구분처럼 총칙에서 1문제 안팎이 나온다.

- **거주자**: 국내에 주소를 두거나 **183일 이상** 거소를 둔 개인. 국내외 모든 소득에 과세(무제한 납세의무). 비거주자는 국내원천소득에만 과세한다.
- **과세기간**: 1월 1일~12월 31일. 거주자가 사망하면 사망일까지, 출국해 비거주자가 되면 출국일까지로 단축된다.
- **납세지**: 거주자는 주소지(주소가 없으면 거소지), 비거주자는 국내사업장 소재지.
- **과세방법**
    - 종합과세: 이자·배당·사업·근로·연금·기타소득을 합산해 기본세율 **6~45%**로 과세.
    - 분류과세: 퇴직소득, 양도소득은 따로 과세.
    - 분리과세: 원천징수로 납세의무를 끝낸다(예: 2,000만원 이하 금융소득).
- **확정신고**: 다음 해 **5월 1일~31일**.

!!! warning "자주 나오는 함정"
    - 퇴직소득과 양도소득은 종합소득에 **합산하지 않는다**(분류과세).
    - 소득세는 원칙적으로 개인 단위 과세이다. 부부 합산 과세가 아니다.

## 3. 이자소득, 배당소득 및 양도소득 <span class="star s3">★★★</span> { #ch3 }

**출제 포인트:** 금융소득종합과세 구조(2,000만원 기준, 원천징수세율, Gross-up)와 이자·배당 수입시기가 거의 매회 나오는 핵심이다. 상장주식 양도세(대주주 과세)도 자주 출제된다.

- **이자소득**: 예금이자, 채권 이자·할인액, 환매조건부채권(RP) 매매차익, 저축성보험 보험차익(요건을 갖추면 비과세), 비영업대금의 이익 등.
- **배당소득**: 이익배당, 의제배당, 인정배당, 집합투자기구로부터의 이익, 파생결합증권(ELS 등) 이익, 출자공동사업자 배당 등.
- **수입시기(주요)**

| 구분 | 수입시기 |
|---|---|
| 보통예금·정기예금 이자 | 실제로 이자를 지급받는 날 |
| 무기명 채권 이자 | 지급받는 날 |
| 기명 채권 이자 | 약정에 의한 지급일 |
| 비영업대금의 이익 | 약정에 의한 지급일 |
| 무기명주식 배당 | 지급받는 날 |
| 기명주식 잉여금 처분 배당 | 잉여금 처분 결의일 |

- **원천징수세율**: 일반 이자·배당 **14%**(지방소득세 별도), 비영업대금의 이익 **25%**, 비실명 금융소득 **45%**(금융실명법 대상은 **90%**).
- **금융소득종합과세**: 이자+배당 합계가 연 **2,000만원**을 넘으면 넘는 부분을 다른 종합소득과 합산해 기본세율로 과세한다.
    - **비교과세**: 산출세액은 ① 종합과세 방식(2,000만원까지 14% + 초과분 기본세율)과 ② 금융소득 전액을 원천징수세율로 계산한 금액(+다른 종합소득 기본세율) 중 **큰 금액**이다. 초과분이 낮은 세율 구간에 걸리면 ②가 적용될 수 있다.
    - 무조건 분리과세: 비실명 이자·배당 등.
    - 무조건 종합과세: 국외에서 받아 원천징수되지 않은 이자·배당, 출자공동사업자의 배당.
    - 조건부 종합과세: 그 밖의 일반 금융소득(합계 2,000만원 초과 시 종합과세).
- **Gross-up(배당가산)**: 법인세가 과세된 내국법인 배당 중 2,000만원 초과분에 대해 배당액의 **10%**(2024년 귀속분부터)를 더하고, 같은 금액을 배당세액공제로 빼서 이중과세를 조정한다.

\[ \text{종합과세 금융소득금액} = \text{이자} + \text{배당} + \text{Gross-up 대상 배당} \times 10\% \]

- **양도소득(주식)**: 상장주식은 **대주주** 양도분과 장외 양도분만 과세. 국외주식은 양도차익에 과세하며 기본공제 연 **250만원**.
- **대주주 상장주식 세율**: 과세표준 3억원 이하 **20%**, 3억원 초과 **25%**(중소기업 외 법인 대주주가 1년 미만 보유하면 **30%**).
- 대주주 판정의 시가총액 기준(현행 종목당 **50억원**)은 개정 논의가 잦았다 (최신 기본서 확인).

!!! warning "자주 나오는 함정"
    - 기준은 "이자+배당 합계" **2,000만원**이고, **초과분**만 기본세율로 과세한다(2,000만원 이하분은 14%). 단, 최종 세액은 **비교과세**로 원천징수 방식과 비교해 큰 금액이다.
    - 집합투자기구(펀드) 이익과 ELS 분배금은 **이자소득이 아니라 배당소득**이다.
    - 국내 상장주식이라도 소액주주가 **장외**에서 양도하면 양도소득세 과세 대상이다.
    - 금융투자소득세는 시행 전에 **폐지**됐다(2024년 말 법 개정). 시행 중인 제도로 낸 선지는 오답이다.

## 4. 증권거래세법 <span class="star s2">★★</span> { #ch4 }

**출제 포인트:** 납세의무자와 세율, 신고 기한을 묻는다. 세율은 연도별로 바뀌었으므로 기본서 기준 연도를 확인해야 한다.

- **과세대상**: 주권 또는 지분의 **양도**(매도). 손익과 관계없이 **양도가액**에 세율을 곱한다.
- **납세의무자**: 장내·장외 결제를 하는 경우 예탁결제원, 금융투자업자를 통해 양도하면 해당 금융투자업자, 그 밖에는 양도자.
- **신고·납부**: 매월분을 다음 달 **10일**까지(예탁결제원·금융투자업자 기준).
- **비과세**: 국가·지방자치단체가 주권을 양도하는 경우, 상장을 위한 주식 매출 등.
- **세율(상장주식)** (최신 기본서 확인)

| 시장 | 2025년 | 2026년 |
|---|---|---|
| 코스피 | 0% + 농어촌특별세 0.15% | **0.05%** + 농어촌특별세 0.15% |
| 코스닥 | 0.15% | **0.20%** |
| K-OTC | 0.15% | 0.20% |
| 비상장(K-OTC 외 장외) | 0.35% | 0.35% |

!!! warning "자주 나오는 함정"
    - 매수자가 아니라 **양도자(매도) 쪽**에 과세한다.
    - 코스피는 증권거래세와 **농어촌특별세**를 합한 실효세율로 묻는 경우가 많다.

## 5. 기타 금융세제 <span class="star s2">★★</span> { #ch5 }

**출제 포인트:** 상속·증여세 세율, 신고기한, 증여재산공제 금액과 연금계좌 세액공제를 묻는다.

- **상속·증여세 세율**: 10~50% 5단계 초과누진세율.
- **신고기한**: 상속세는 상속개시일이 속하는 달 말일부터 **6개월**, 증여세는 증여일이 속하는 달 말일부터 **3개월**. 기한 내 신고하면 신고세액공제 **3%**.
- **증여재산공제(10년 합산)**

| 증여자 | 공제액 |
|---|---|
| 배우자 | **6억원** |
| 직계존속 → 성년 자녀 | **5,000만원**(미성년 2,000만원) |
| 직계비속 → 부모 | **5,000만원** |
| 기타 친족 | **1,000만원** |

- **상장주식 평가**: 평가기준일 전후 각 **2개월**(총 4개월) 종가 평균.
- **연금계좌**: 세액공제 대상 납입한도는 연금저축 **600만원**, IRP 합산 **900만원**. 세액공제율 13.2%(총급여 5,500만원 이하 16.5%, 지방세 포함).
- **ISA**: 납입한도·비과세 한도·의무가입기간은 최근 개편 논의가 있었다 (최신 기본서 확인).

!!! warning "자주 나오는 함정"
    - 증여재산공제는 **1회**가 아니라 **10년간 합산** 기준이다.
    - 상속세는 6개월, 증여세는 3개월이다. 두 기한을 바꿔 낸 선지가 자주 나온다.

## 6. 세무전략 : 금융자산 TAX-PLANNING <span class="star s1">★</span> { #ch6 }

**출제 포인트:** 앞 챕터 제도를 응용해 "절세 방법으로 옳지 않은 것"을 고르게 하는 문제가 가끔 나온다.

- 금융소득이 2,000만원을 넘지 않도록 **소득을 시기별·가족별로 분산**한다.
- 비과세·분리과세 상품(ISA, 연금계좌, 장기 저축성보험)을 활용한다.
- 증여재산공제(10년 단위)를 고려해 **미리, 나누어 증여**한다.
- 상장주식 매매차익(소액주주)은 비과세라 이자·배당보다 세 부담이 낮다.
