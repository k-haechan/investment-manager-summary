## 1. 부동산 투자의 기초 <span class="star s1">★</span> { #ch1 }

**출제 포인트:** 부동산 개념과 권리 관련 기본 용어를 묻는 정도이다.

- 부동산은 물리적(공간·자연·위치), 경제적(자산·생산요소·소비재), 법률적(소유권 등 권리) 측면을 함께 가진 **복합개념**이다.
- 법률상 부동산: 토지와 그 정착물. 소유권 외에 지상권, 지역권, 전세권(용익물권)과 저당권(담보물권) 등이 설정된다.
- **법률행위**(매매·증여 등)에 의한 부동산 물권 변동은 **등기**해야 효력이 생긴다(민법 186조). 상속·공용징수·판결·경매 등 **법률 규정**에 의한 취득은 등기 없이 효력이 생기고, 처분할 때 등기가 필요하다(민법 187조).

## 2. 부동산 투자의 이해 <span class="star s2">★★</span> { #ch2 }

**출제 포인트:** 부동산 특성의 분류(자연적 vs 인문적)와 부동산 투자 위험을 묻는다.

| 자연적 특성 | 인문적 특성 |
|---|---|
| 부동성(지리적 위치 고정) | 용도의 다양성 |
| 영속성(물리적으로 소모되지 않음) | 합병·분할 가능성 |
| 부증성(양을 늘릴 수 없음) | 사회적·경제적·행정적 위치의 가변성 |
| 개별성(같은 부동산이 없음) | |

- **부동산 투자의 특징**: 거래 단위가 커서 소액 투자가 어렵고, **유동성이 낮으며**, 거래비용이 크다. 레버리지를 쓰기 쉽고, 인플레이션 헤지 효과가 있다.
- **투자 위험**: 사업위험(시장·운영·입지), 금융위험(차입), 법적위험, 인플레이션위험, 유동성위험.
- **경기변동**: 회복 → 호황 → 후퇴 → 불황 4국면에 안정시장을 더해 설명한다. 부동산 경기는 일반 경기보다 **늦게** 움직이고 진폭이 크다.

## 3. 부동산의 이용 및 개발 <span class="star s2">★★</span> { #ch3 }

**출제 포인트:** 건폐율·용적률 정의와 용도지역 구분, 개발방식 구분을 묻는다.

- **용도지역**: 도시지역(주거·상업·공업·녹지), 관리지역, 농림지역, 자연환경보전지역.

\[ \text{건폐율} = \frac{\text{건축면적}}{\text{대지면적}}, \qquad \text{용적률} = \frac{\text{지상층 연면적}}{\text{대지면적}} \]

- **개발방식**: 자체개발, 지주공동사업(등가교환, 사업수탁, 토지신탁, 차지개발 등).
    - 등가교환: 토지소유자가 토지를, 개발업자가 건축비를 내고 완성 건물을 지분 비율대로 나눈다.
    - 사업수탁: 개발업자가 사업 전반을 맡고 토지소유자가 자금을 부담한다.
    - 토지신탁: 신탁회사에 토지를 맡겨 개발한다.

!!! warning "자주 나오는 함정"
    - 용적률 연면적에는 **지하층**을 넣지 않는다(지상층 기준).

## 4. 부동산 투자 구분 <span class="star s1">★</span> { #ch4 }

**출제 포인트:** 투자 방식 분류를 묻는 기본 문제 수준이다.

- 직접투자(실물 매입) vs 간접투자(리츠, 부동산펀드 등).
- 실물투자 vs 금융투자(대출·유동화증권 등 부동산 관련 금융상품).
- 공모 vs 사모, 지분(Equity) vs 대출(Debt) 투자로도 나눈다.

## 5. 부동산 펀드의 이해 <span class="star s3">★★★</span> { #ch5 }

**출제 포인트:** 부동산 펀드 정의(50% 초과), 투자 대상, 유형별 특징, 차입·대여 한도를 묻는 문제가 가장 자주 나온다.

- **정의**: 집합투자재산의 **50%를 초과**해 부동산 등에 투자하는 집합투자기구.
- **부동산 등의 범위**: 부동산 취득·개발·관리·임대, 부동산 개발 관련 법인에 대한 **대출**, 부동산 관련 권리(지상권, 지역권, 전세권, 임차권, 분양권 등), 부동산 관련 증권(리츠 주식, 부동산 ABS, 부동산펀드 지분 등).
- **유형**

| 유형 | 내용 |
|---|---|
| 임대형 | 부동산을 매입해 임대수익을 얻고 매각차익을 추구 |
| 대출형(PF형) | 개발사업 시행사에 대출하고 이자를 받음. 시공사 보증 등 신용보강이 핵심 |
| 경공매형 | 경매·공매 부동산을 싸게 사서 임대·매각 |
| 개발형 | 펀드가 직접 시행사가 되어 개발 후 분양·임대 |
| 개량형 | 부동산을 개량해 가치를 높인 뒤 임대·매각 |
| 권리형 | 지상권·임차권 등 부동산 관련 권리에 투자 |
| 증권형 | 부동산 관련 증권에 투자 |

- **차입·대여 한도**: 부동산펀드는 순자산의 **200%**까지 차입할 수 있고, 부동산 개발사업 법인 등에 순자산의 **100%**까지 대여할 수 있다 (최신 기본서 확인).
- **처분 제한**: 취득한 부동산은 일정 기간 안에 처분할 수 없고(국내 부동산 **1년**), 토지는 개발사업 시행 전에 처분할 수 없다 (최신 기본서 확인).
- 공모 부동산펀드는 대부분 **환매금지형**으로 설정한다.

!!! warning "자주 나오는 함정"
    - 대출형 펀드의 핵심 위험은 시행사·시공사의 **신용위험**이다(임대형은 공실·임대료 위험).
    - 경공매형은 좋은 물건을 찾을 때까지 자금이 놀아(미운용) 수익률이 떨어질 수 있다.

## 7. 부동산 가치평가 <span class="star s2">★★</span> { #ch7 }

**출제 포인트:** 감정평가 3방식과 각 방식의 세부 방법을 짝짓는 문제가 나온다.

| 방식 | 가격을 구하는 방법 | 임료를 구하는 방법 | 원리 |
|---|---|---|---|
| 원가방식 | 원가법(재조달원가 − 감가수정) | 적산법 | 비용성 |
| 비교방식 | 거래사례비교법 | 임대사례비교법 | 시장성 |
| 수익방식 | 수익환원법 | 수익분석법 | 수익성 |

- **수익환원법**: 장래 순수익을 환원율로 나누거나(직접환원법) 미래 현금흐름을 할인(할인현금흐름분석법)해 가치를 구한다.

\[ \text{가치} = \frac{\text{순영업소득(NOI)}}{\text{자본환원율}} \]

## 8. 부동산의 투자가치 분석 <span class="star s3">★★★</span> { #ch8 }

**출제 포인트:** 현금흐름 계산 단계와 NPV·IRR 판단 기준, 레버리지 효과, 대출 관련 비율을 계산·개념 문제로 낸다.

- **현금흐름 계산 순서**

| 단계 | 계산 |
|---|---|
| 가능총소득(PGI) | 임대 가능 면적 × 임대료 |
| 유효총소득(EGI) | 가능총소득 − 공실·대손 + 기타소득 |
| 순영업소득(NOI) | 유효총소득 − **영업경비** |
| 세전현금흐름(BTCF) | 순영업소득 − **부채서비스액**(원리금 상환액) |
| 세후현금흐름(ATCF) | 세전현금흐름 − 영업소득세 |

- 영업경비에는 감가상각비, 부채서비스액, 소득세를 **넣지 않는다**.
- **할인현금흐름분석**
    - **NPV** = 유입 현금흐름 현재가치 − 유출 현금흐름 현재가치. NPV ≥ 0이면 투자한다.
    - **IRR**: NPV를 0으로 만드는 할인율. IRR ≥ 요구수익률이면 투자한다.
    - **수익성지수(PI)** = 유입 현가 ÷ 유출 현가. PI ≥ 1이면 투자한다.
- **레버리지 효과**: 총자본수익률이 차입이자율보다 높으면 차입을 늘릴수록 자기자본수익률이 커진다(정의 레버리지).

\[ R_E = R_A + (R_A - R_D)\times\frac{D}{E} \]

- **대출 관련 비율**
    - 부채감당률(DSCR) = NOI ÷ 부채서비스액. **1보다 커야** 원리금을 감당할 수 있다.
    - 담보인정비율(LTV) = 대출금 ÷ 부동산 가치.

!!! warning "자주 나오는 함정"
    - NPV법은 재투자수익률을 **요구수익률**로, IRR법은 **IRR**로 가정한다. 둘이 다른 결론을 낼 때는 NPV법을 우선한다.
    - 차입이자율이 총자본수익률보다 높으면 **부의 레버리지**가 되어 차입할수록 자기자본수익률이 떨어진다.

## 9. 부동산 개발사업 사업타당성 평가 <span class="star s1">★</span> { #ch9 }

**출제 포인트:** 타당성 분석의 단계와 구성 요소를 묻는 정도이다.

- 시장분석(수요·공급, 입지), 법률·행정적 타당성(인허가, 용도 규제), 물리적·기술적 타당성, **경제적(재무적) 타당성**(NPV·IRR 등)을 검토한다.
- 개발사업 위험: 인허가 위험, 공사 지연·비용 초과 위험, 분양(시장) 위험.

## 10. 부동산 간접투자제도의 이해 <span class="star s2">★★</span> { #ch10 }

**출제 포인트:** 리츠와 부동산펀드의 근거법·감독기관·형태를 비교한다.

| 구분 | 리츠(부동산투자회사) | 부동산펀드 |
|---|---|---|
| 근거법 | 부동산투자회사법 | 자본시장법 |
| 감독 | 국토교통부(인가·등록) | 금융위원회 |
| 법적 형태 | 주식회사 | 투자신탁 중심(회사형도 가능) |
| 자산운용 | 자기관리: 직접 / 위탁관리·CR: 자산관리회사(AMC)에 위탁 | 집합투자업자 |

- **PFV(프로젝트금융투자회사)**: 개발사업 하나를 위해 만든 명목회사. 법인세법상 요건을 갖추면 배당금 소득공제를 받는다.

| 구분 | 자기관리 리츠 | 위탁관리 리츠 | 기업구조조정(CR) 리츠 |
|---|---|---|---|
| 형태 | **실체회사**(상근 임직원) | **명목회사** | **명목회사** |
| 자산운용 | 직접 운용 | 자산관리회사에 위탁 | 자산관리회사에 위탁 |
| 투자대상 | 일반 부동산 | 일반 부동산 | 기업구조조정용 부동산(총자산의 70% 이상) |
| 최저자본금(영업인가 후 6개월 경과) | **70억원** | **50억원** | **50억원** |
| 주식 분산·공모 의무 | 적용 | 적용 | 적용 제외 |

- **설립자본금**: 자기관리 리츠 5억원, 위탁관리·CR 리츠 3억원 (최신 기본서 확인).
- **주식 분산**: 주주 1인과 특별관계자는 발행주식 총수의 **50%**를 초과해 소유할 수 없다.
- **주식 공모**: 영업인가·등록일부터 **3년**(프로젝트 리츠는 **5년**) 이내에 발행주식 총수의 **30%** 이상을 일반 청약에 제공해야 한다(연기금 등이 일정 비율 이상 인수하면 예외). 기본서 판본에 따라 기간 표기가 다를 수 있다 (최신 기본서 확인).
- **자산 구성**(매 분기 말): 총자산의 **80%** 이상을 부동산, 부동산 관련 증권, 현금으로 구성하고, 이 중 총자산의 **70%** 이상은 부동산(건축 중인 건축물 포함)이어야 한다.
- **배당**: 이익배당한도의 **90%** 이상을 배당해야 한다. 위탁관리·CR 리츠는 감가상각비 범위에서 초과배당할 수 있다. 자기관리 리츠에 대한 배당 특례 비율은 (최신 기본서 확인).

!!! warning "자주 나오는 함정"
    - 상근 임직원을 둘 수 있는 리츠는 **자기관리 리츠뿐**이다. 위탁관리·CR 리츠는 본점 외 지점을 둘 수 없고 직원도 없다.
    - CR 리츠는 주식 분산·공모 의무를 **적용받지 않는다**.
    - 최저자본금은 자기관리 70억원, 나머지 50억원이다. 숫자를 서로 바꾼 선지가 자주 나온다.
