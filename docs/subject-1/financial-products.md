## 1. 금융회사의 종류 <span class="star s1">★</span> { #ch1 }

**출제 포인트:** 어떤 기관이 어느 분류에 속하는지 묻는 문제가 가끔 나옵니다.

- **은행**: 일반은행(시중·지방·외국은행 국내지점, 인터넷전문은행), 특수은행(산업은행, 수출입은행, 기업은행, 농협·수협 신용사업 부문).
- **비은행예금취급기관**: 상호저축은행, 신용협동조합, 새마을금고, 상호금융, 우체국예금.
- **금융투자업자**: 투자매매업, 투자중개업, 집합투자업, 투자자문업, 투자일임업, 신탁업(6종).
- **보험회사**와 **기타 금융기관**(여신전문금융회사 등).

## 2. 금융상품의 개요 <span class="star s2">★★</span> { #ch2 }

**출제 포인트:** 예금자보호 대상인지 아닌지를 고르는 문제가 대표적입니다.

- **보호한도**: 금융회사별 1인당 원금+이자 **1억원**(2025.9.1 시행, 종전 5,000만원).

| 보호 대상 | 보호 비대상 |
|---|---|
| 보통·정기·적립식 예금, 외화예금 | CD(양도성예금증서), RP(환매조건부채권) |
| 표지어음 | 펀드 등 금융투자상품 |
| 원금보전형 신탁 | 실적배당형 신탁 |
| 개인 보험계약(변액보험은 최저보증 부분 등만) | 은행 발행 채권, 주택청약종합저축(정부가 별도 관리) |
| 증권사 예탁금(현금 잔액) | 증권사 CMA 중 RP형·MMF형 등 |

!!! warning "자주 나오는 함정"
    - CD와 RP는 은행·증권사 상품이라도 **예금자보호 대상이 아닙니다**.
    - 주택청약종합저축은 예금자보호법 대상이 아니지만, 주택도시기금으로 정부가 관리합니다.

## 3. 예금의 구분 <span class="star s1">★</span> { #ch3 }

**출제 포인트:** 상품을 요구불·저축성으로 분류하는 기본 문제 수준입니다.

- **요구불예금**: 보통예금, 당좌예금, 가계당좌예금. 언제든 인출할 수 있고 이자가 낮습니다.
- **저축성예금**: 거치식(정기예금), 적립식(정기적금, 상호부금), 시장금리부 수시입출식(MMDA) 등.
- 입출금 방식에 따라 입출금자유, 거치식, 적립식으로 나누기도 합니다.

## 4. 예금의 종류 <span class="star s2">★★</span> { #ch4 }

**출제 포인트:** CD, 표지어음, MMDA의 특징을 섞어서 "옳지 않은 것"으로 냅니다.

| 상품 | 특징 |
|---|---|
| MMDA | 시장금리를 반영하는 수시입출식 예금. 예치 금액별로 금리를 차등. 예금자보호 대상 |
| CD | **무기명·할인식** 발행, 양도 가능, **중도해지 불가**. 예금자보호 비대상 |
| 표지어음 | 은행이 할인 보유한 어음을 바탕으로 발행. 중도해지 불가. 예금자보호 대상 |
| 주택청약종합저축 | 국민주택·민영주택 청약 모두 가능. 1인 1계좌 |

!!! warning "자주 나오는 함정"
    - CD는 중도해지가 안 되므로 유통시장에서 **매각**해 현금화합니다.
    - 표지어음과 CD는 둘 다 할인식이지만, 예금자보호 여부가 서로 다릅니다.

## 5. 신탁상품의 개념과 특징 <span class="star s2">★★</span> { #ch5 }

**출제 포인트:** 신탁 3당사자 관계와 신탁재산 독립성의 효과를 묻습니다.

- **당사자**: 위탁자(재산을 맡김), 수탁자(신탁회사, 관리·처분), 수익자(이익을 받음). 위탁자=수익자이면 자익신탁, 다르면 타익신탁.
- **신탁재산의 독립성**: 신탁재산은 수탁자의 고유재산과 분리됩니다.
    - 수탁자의 채권자는 신탁재산에 **강제집행할 수 없습니다**.
    - 수탁자가 파산해도 신탁재산은 **파산재단에 포함되지 않습니다**.
    - 신탁재산에 속한 채권과 고유재산에 속한 채무는 상계할 수 없습니다.
- **실적배당** 원칙: 원본과 이익을 보전하지 않는 것이 원칙입니다(연금신탁 등 일부 예외).
- **분별관리 의무**: 수탁자는 신탁재산을 고유재산과 구분해 관리해야 합니다.

## 6. 신탁상품의 종류 <span class="star s3">★★★</span> { #ch6 }

**출제 포인트:** 금전신탁과 재산신탁의 구분, 특정금전신탁의 운용지시 구조, 부동산신탁 4유형이 단골입니다.

- **금전신탁**: 금전을 맡기고 운용 후 금전으로 돌려받습니다.
    - **특정금전신탁**: **위탁자가 운용 방법을 지정**합니다. 고객별로 운용(단독 운용). MMT(수시입출식 특정금전신탁)가 대표 상품입니다.
    - **불특정금전신탁**: 수탁자가 운용 방법을 정하고 여러 고객 자금을 합동 운용합니다. 펀드와 성격이 겹쳐 현재는 연금신탁 등 일부를 빼고 **신규 수탁이 금지**되어 있습니다.
- **재산신탁**: 증권신탁, 금전채권신탁, 동산신탁, 부동산신탁 등. 맡긴 재산 그대로 돌려줄 수 있습니다.
- **부동산신탁 유형**

| 유형 | 내용 |
|---|---|
| 관리신탁 | 소유권 관리, 임대 관리 등 부동산 관리를 맡김 |
| 처분신탁 | 처분이 어려운 부동산의 매각을 맡김 |
| 담보신탁 | 부동산을 신탁하고 수익권증서를 담보로 대출 |
| 토지(개발)신탁 | 신탁회사가 자금을 조달해 개발하고 분양·임대 수익을 배분. 차입형과 관리형으로 구분 |

- **종합재산신탁**: 금전, 증권, 부동산 등 여러 재산을 하나의 계약으로 맡깁니다.
- **연금신탁**: 연금저축신탁. 2018년 이후 신규 판매가 중단됐습니다 (최신 기본서 확인).

!!! warning "자주 나오는 함정"
    - 운용지시권은 특정금전신탁에서는 **위탁자**, 불특정금전신탁에서는 **수탁자**에게 있습니다.
    - 담보신탁은 저당권 설정보다 비용이 적고, 신탁된 부동산은 위탁자 채권자의 강제집행을 피할 수 있습니다.

## 7. 생명보험상품 <span class="star s2">★★</span> { #ch7 }

**출제 포인트:** 보험금 지급 사유별 분류와 변액보험의 특징을 묻습니다.

- **사망보험**: 피보험자가 사망하면 지급(정기보험, 종신보험).
- **생존보험**: 만기까지 생존하면 지급(연금보험 등).
- **생사혼합보험(양로보험)**: 사망보험과 생존보험을 결합한 형태.
- **변액보험**: 보험료 일부를 **특별계정**(펀드)에서 운용해 실적에 따라 보험금·해지환급금이 바뀝니다. 최저보증 부분을 제외하면 예금자보호 대상이 아닙니다.
- **유니버셜보험**: 보험료 납입과 적립금 인출이 자유롭습니다.
- **CI보험**: 중대한 질병이 발생하면 사망보험금 일부를 미리 지급합니다.

## 8. 손해보험상품 <span class="star s1">★</span> { #ch8 }

**출제 포인트:** 생명보험과 다른 보상 원리를 가끔 묻습니다.

- **실손보상 원칙**: 실제 손해액만큼만 보상(이득 금지). 생명보험은 약정 금액을 지급하는 정액보상입니다.
- **비례보상**: 보험가액보다 보험가입금액이 적으면(일부보험) 비율에 따라 보상합니다.
- 종류: 화재, 해상, 자동차, 배상책임, 장기손해보험(저축 기능 포함) 등.

## 9. 금융투자상품의 개념 및 종류 <span class="star s2">★★</span> { #ch9 }

**출제 포인트:** 금융투자상품 정의(원본손실 가능성)와 증권·파생상품 구분, 증권 6종 분류를 묻습니다.

- **정의**: 이익을 얻거나 손실을 회피할 목적으로, 투자금액이 회수금액을 넘을 위험(**원본손실 가능성**, 투자성)이 있는 권리.
- 투자금액에서 판매수수료는 빼고, 회수금액에서 환매·해지수수료와 세금 등은 더해 계산합니다.
- **증권**(원본까지만 손실 가능): 채무증권, 지분증권, 수익증권, 투자계약증권, 파생결합증권, 증권예탁증권(**6종**).
- **파생상품**(원본 초과 손실 가능): 장내파생상품, 장외파생상품.
- **명시적 제외**: 원화 표시 CD, 관리형신탁 수익권, 주식매수선택권(스톡옵션).

## 10. 펀드상품 <span class="star s3">★★★</span> { #ch10 }

**출제 포인트:** 집합투자기구 종류별 투자 대상, 특수한 형태의 펀드 특징을 비교하는 문제가 매년 나옵니다.

- **법적 형태**: 투자신탁(가장 일반적), 투자회사(뮤추얼펀드), 투자유한회사, 투자합자회사, 투자유한책임회사, 투자합자조합, 투자익명조합.
- **운용대상별 5종류**

| 종류 | 기준 |
|---|---|
| 증권 집합투자기구 | 집합투자재산의 50% 초과를 증권에 투자 |
| 부동산 집합투자기구 | 50% 초과를 부동산(관련 대출·증권 포함)에 투자 |
| 특별자산 집합투자기구 | 50% 초과를 특별자산에 투자 |
| 혼합자산 집합투자기구 | 투자 비율 제한 없이 위 자산에 투자 |
| 단기금융 집합투자기구(MMF) | 전부를 단기금융상품에 투자 |

- **특수한 형태**
    - **환매금지형**: 환매를 청구할 수 없는 폐쇄형. 부동산·특별자산 등 유동성이 낮은 자산에 투자할 때 사용. 공모로 설정하면 **90일** 이내에 상장해야 합니다.
    - **종류형**(멀티클래스): 판매보수·수수료가 다른 여러 클래스를 하나의 펀드로 운용.
    - **전환형**: 정해진 다른 펀드로 전환할 수 있습니다. 전환 시 환매수수료를 받지 않습니다.
    - **모자형**: 자펀드가 모펀드에 투자하고, 실제 운용은 모펀드가 합니다.
    - **상장지수(ETF)**: 지수를 추종하고 거래소에 상장돼 주식처럼 거래합니다.
- **MMF**: 장부가로 평가하고 잔존만기 등 엄격한 운용 제한이 있습니다.

!!! warning "자주 나오는 함정"
    - 혼합자산 집합투자기구는 **투자 비율 제한이 없습니다**. "50% 초과" 기준을 붙인 선지는 오답입니다.
    - 모자형에서 투자자는 **자펀드**에만 가입합니다. 모펀드를 직접 사지 않습니다.
    - MMF는 단기금융상품만 운용하므로 **장기채권·주식에 투자할 수 없습니다**.

## 11. 기타 금융투자상품 <span class="star s3">★★★</span> { #ch11 }

**출제 포인트:** 주가연계 상품 4종(ELS·ELD·ELF·ELW) 비교가 가장 자주 나옵니다. 랩어카운트, CMA, ETN 특징도 함께 출제됩니다.

| 구분 | ELD | ELS | ELF | ELW |
|---|---|---|---|---|
| 발행·운용 | 은행(예금) | 증권사(파생결합증권) | 자산운용사(펀드) | 증권사(상장 파생결합증권) |
| 원금 보장 | 원금 보장 | 상품별로 다름 | 보장 없음(보존 추구형 존재) | 보장 없음 |
| 예금자보호 | **대상** | 비대상 | 비대상 | 비대상 |
| 특징 | 이자를 주가에 연동 | 수익구조 다양(조기상환형 등) | ELS 등에 투자하는 펀드 | 주식처럼 거래소에서 매매 |

- **랩어카운트**: 증권사가 고객 자산을 일괄 운용하고 잔고에 비례해 **수수료(wrap fee)를 한꺼번에** 받는 계좌. 일임형과 자문형이 있습니다.
- **CMA**: 고객 예탁금을 RP·MMF·MMW 등에 자동 투자하는 수시입출 계좌. 종합금융회사형 CMA만 예금자보호 대상입니다.
- **ETN**: 증권사가 발행하고 기초지수 수익을 지급하는 **상장 파생결합증권**. 발행자의 신용위험이 있습니다(ETF는 신탁재산으로 분리 보관).
- **ELB·DLB**: 원금보장형 파생결합사채.

!!! warning "자주 나오는 함정"
    - ETF는 집합투자증권(펀드), ETN은 파생결합증권(발행 증권사의 채무)입니다. **신용위험은 ETN에 있습니다**.
    - ELD는 은행 **예금**이라 예금자보호 대상이고, 이름이 비슷한 ELS·ELF는 비대상입니다.

## 12. 자산유동화증권(ABS)의 기본개념 <span class="star s3">★★★</span> { #ch12 }

**출제 포인트:** 유동화 참여자의 역할, 진정한 매각 요건, 신용보강 방식(내부·외부)을 구분하는 문제가 자주 나옵니다.

- **정의**: 자산보유자가 보유한 대출채권·매출채권 등 유동화자산을 SPC에 넘기고, SPC가 그 자산의 현금흐름을 바탕으로 발행한 증권.
- **발행 이유(자산보유자)**: 유동성 확보, 자금조달 수단 다양화, 조달비용 절감(자산보유자보다 높은 신용등급 가능), 재무비율 개선(부외 처리).
- **진정한 매각(true sale)**: 자산보유자가 파산해도 유동화자산이 파산재산에 들어가지 않도록 양도해야 합니다.
- **신용보강**

| 구분 | 방법 |
|---|---|
| 내부 신용보강 | 선·후순위 구조(후순위채 발행), 초과담보, 현금흐름 차액 적립(Spread Account), 자산보유자의 환매 약정 |
| 외부 신용보강 | 은행 등의 지급보증, 신용공여(Credit Line), 보험 |

- **장점(투자자)**: 신용등급이 상대적으로 높고, 같은 등급 회사채보다 수익률이 높은 경우가 많습니다.
- **단점**: 구조가 복잡하고 발행 비용(신용평가·법률·회계)이 큽니다. 일정 규모 이상이어야 경제성이 있습니다.

!!! warning "자주 나오는 함정"
    - 후순위채 발행은 **외부**가 아니라 **내부** 신용보강입니다.
    - ABS 신용등급은 자산보유자의 신용이 아니라 **유동화자산의 현금흐름과 신용보강**으로 결정됩니다.

## 13. 자산유동화증권의 구조 <span class="star s2">★★</span> { #ch13 }

**출제 포인트:** Pass-through와 Pay-through를 비교하고, 참여자 역할을 짝짓는 문제가 나옵니다.

| 구분 | Pass-through | Pay-through |
|---|---|---|
| 형태 | 지분형(수익증권·출자증권) | 채권형 |
| 현금흐름 | 기초자산 현금흐름을 **그대로** 투자자에게 이전 | 기초자산 현금흐름을 **재조정**해 만기·이자 구조가 다른 여러 트랜치로 지급 |
| 조기상환위험 | 투자자가 그대로 부담 | 트랜치별로 재배분 |

- **참여자**: 자산보유자(Originator), 유동화전문회사(SPC, 명목회사), 자산관리자(Servicer, 채권 추심·관리, 보통 자산보유자가 겸함), 신용평가기관, 신용보강기관, 수탁기관(자산 보관), 주관사.

## 14. 자산유동화증권 주요 발행유형 <span class="star s2">★★</span> { #ch14 }

**출제 포인트:** 기초자산에 따른 ABS 이름과 특징을 짝짓습니다.

- **CBO**: 회사채를 기초자산으로 발행. 신규 발행 회사채를 담는 **발행시장 CBO**(P-CBO), 이미 발행된 회사채를 담는 **유통시장 CBO**.
- **CLO**: 금융기관 대출채권(무수익채권 포함)을 기초자산으로 발행.
- **ABCP**: ABS를 기업어음(CP) 형태로 발행. 장기 자산을 단기로 차환 발행하므로 **차환(유동성) 위험**이 있습니다.
- **카드채권 ABS**: 만기가 짧은 카드채권을 계속 새 채권으로 채워 넣는 **리볼빙 구조**. 조기상환 사유가 생기면 원금을 조기 상환합니다.
- **자동차할부채권 ABS**, 부동산 PF ABS 등.

## 15. 주택저당증권(MBS) <span class="star s2">★★</span> { #ch15 }

**출제 포인트:** MBS 특유의 조기상환위험과 현금흐름 특징을 묻습니다.

- **정의**: 주택저당채권(모기지)을 기초자산으로 발행한 ABS. 한국은 **한국주택금융공사**가 주로 발행하고 지급을 보증합니다.
- **특징**
    - 대출자가 금리 하락기에 원금을 미리 갚는 **조기상환위험**이 있어 현금흐름이 불확실합니다.
    - 원리금이 **매월** 들어옵니다.
    - 만기가 길고, 공사 보증 등으로 신용등급이 높습니다.
    - 위험이 커서 같은 등급 국채보다 수익률이 높습니다.
- 조기상환은 금리 하락기에 늘어 재투자 수익률이 떨어지므로, 투자자에게 불리하게 작용합니다(음의 볼록성).

!!! warning "자주 나오는 함정"
    - 금리가 **떨어지면** 조기상환이 **늘어납니다**. 반대로 낸 선지에 주의하세요.

## 16. 퇴직연금제도 <span class="star s3">★★★</span> { #ch16 }

**출제 포인트:** DB형과 DC형 비교(운용 책임, 급여 수준, 위험 부담)가 거의 매회 나오고, IRP 특징과 위험자산 한도가 덧붙여집니다.

| 구분 | 확정급여형(DB) | 확정기여형(DC) |
|---|---|---|
| 급여 | 사전에 **확정**(퇴직금과 같은 수준) | 운용 실적에 따라 **변동** |
| 부담금 | 운용 결과에 따라 회사 부담이 변동 | 연간 임금총액의 **1/12 이상**으로 확정 |
| 운용 주체·위험 | **회사** | **근로자** |
| 중도인출 | 불가 | 법정 사유가 있으면 가능(무주택자 주택 구입 등) |
| 유리한 경우 | 임금상승률이 높고 장기 근속하는 근로자 | 임금 체불 위험이 있거나 이직이 잦은 근로자, 연봉제 |

- **IRP(개인형 퇴직연금)**: 퇴직급여를 받거나 개인이 추가 납입하는 계좌. 연금저축과 합산해 연 **1,800만원**까지 납입할 수 있고 세액공제 한도는 합산 900만원입니다.
- **위험자산 투자한도**: DC·IRP 적립금의 **70%**까지(주식형 펀드 등 위험자산). 원리금보장상품과 TDF 등 일부 적격 상품은 한도 없이 담을 수 있습니다 (최신 기본서 확인).
- **수령**: 55세 이상이면 연금으로 받을 수 있고, 연금 수령기간은 5년 이상이어야 합니다.

!!! warning "자주 나오는 함정"
    - DB형에서 운용 손실 위험은 **회사**가, DC형에서는 **근로자**가 집니다.
    - DB형은 **중도인출이 안 됩니다**(담보 제공은 일정 요건 하에 가능).
