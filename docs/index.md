# 투자자산운용사 핵심요약집

투자자산운용사 시험을 **과목 → 단원 → 챕터** 순서로 정리하고, 챕터마다 기출 빈출도를 별점으로 표시했습니다.

| 별점 | 의미 | 학습 우선순위 |
|---|---|---|
| <span class="star s3">★★★</span> | 거의 매회 출제 | 반드시 암기 |
| <span class="star s2">★★</span> | 자주 출제 | 개념 이해 + 핵심 숫자 |
| <span class="star s1">★</span> | 가끔 출제 | 시간이 남으면 |

별점을 정한 방식과 출처는 [별점 기준](guide.md)에 있습니다.

## 시험 개요

금융투자협회 자격시험센터 공식 안내 기준입니다 ([시험개요 > 투자자산운용사](https://license.kofia.or.kr/examInfo/examInfo.do)).

- **문항·시간:** 3과목 100문항, 120분
- **합격 기준:** 과목별 정답률 40% 이상, 전체 정답률 70%(70문항) 이상
- **과락:** 1과목 8문항, 2과목 12문항, 3과목 20문항 미만

!!! tip "공부 순서 제안"
    문항이 많은 단원(투자분석기법 12, 자본시장 관련 법규 11)과 ★★★ 챕터부터 보세요. 과락을 피하려면 과목별로 최소 40%는 확보해야 하니, 한 과목만 깊게 파지 말고 세 과목을 고르게 돌리는 편이 안전합니다.
