# 별점 기준

## 왜 추정치인가

금융투자협회는 투자자산운용사 회차별 기출문제 원문을 공개하지 않습니다. 그래서 "몇 번 출제됐다"는 정확한 횟수는 누구도 확인할 수 없고, 이 요약집의 별점도 **공개 자료를 교차 집계한 추정치**입니다.

## 별점을 정한 방법

챕터마다 아래 근거를 함께 보고 별점을 정했습니다. 근거의 강도는 단원마다 다릅니다.

1. **기출 복원 횟수:** 회차별 기출 복원 목록에서 해당 챕터 주제가 몇 회차에 나왔는지 셌습니다.
2. **빈출 언급:** 수험 후기, 수험 정보 사이트, 인강 안내에서 "빈출", "매회 출제"로 언급된 주제를 반영했습니다.
3. **문항 배분:** 공식 세부과목 문항수와, 공개된 세부 배분(예: 자본시장법 7·금융위 규정 4·협회규정 3)을 반영했습니다.
4. **출제 구조:** 숫자·공식·비교 포인트가 많아 문제로 만들기 쉬운 챕터일수록 높게 봤습니다.

| 별점 | 기준 |
|---|---|
| <span class="star s3">★★★</span> | 기출 복원·빈출 언급이 반복되거나, 문항 비중이 크고 숫자·공식·비교 포인트가 많은 챕터 |
| <span class="star s2">★★</span> | 일부 자료에서 빈출로 언급되거나, 꾸준히 1문제 안팎 나올 만한 챕터 |
| <span class="star s1">★</span> | 빈출 언급이 거의 없고 지엽적이거나 다른 챕터와 겹치는 챕터 |

### 단원별 근거 강도

| 근거 강도 | 단원 |
|---|---|
| 기출 복원 횟수 반영 (여러 회차) | 주식·채권·파생상품 투자운용, 투자운용결과분석, 거시경제, 분산투자기법 |
| 빈출 언급 + 문항 배분 + 출제 구조 판단 | 세제, 금융상품, 부동산, 대안투자, 해외증권, 투자분석기법, 리스크관리, 직무윤리, 자본시장 관련 법규, 협회규정 |

★★★는 단원 챕터의 대략 1/3 이하를 기본으로 하되, 문항수가 많은 단원에서 계산·단골 주제가 확실한 챕터는 예외로 올렸습니다(예: 리스크관리 신용리스크, 파생상품 선물 총론, 자본시장법 M&A).

두 번째 그룹은 챕터 단위 빈출 자료를 찾지 못해 **판단 비중이 큰 추정치**입니다. 각 단원 페이지 하단에 실제로 참고한 출처를 적었고, 확신이 낮은 수치는 본문에 "(최신 기본서 확인)"으로 표시했습니다.
