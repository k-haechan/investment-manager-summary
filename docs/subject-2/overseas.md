## 1. 해외 투자에 대한 이론적 접근 <span class="star s2">★★</span> { #ch1 }

**출제 포인트:** 국제분산투자가 위험을 줄이는 이유, 환율 변동이 원화 수익률·위험에 미치는 영향을 개념 문제로 낸다.

- 국제분산투자 효과: 국가 간 수익률 **상관관계가 낮아** 국내 분산만으로 제거되지 않는 위험(국내 체계적 위험 일부)까지 줄일 수 있음
- 위기 시에는 국가 간 상관관계가 **높아져** 분산효과가 약해지는 경향
- 외화자산의 원화 환산 수익률(\(R\): 현지통화 수익률, \(e\): 환율변동률)

\[ R_{\text{원화}} = (1+R)(1+e) - 1 \approx R + e \]

- 원화 기준 위험: \(\sigma^2_{\text{원화}} \approx \sigma^2_{R} + \sigma^2_{e} + 2\,\mathrm{Cov}(R, e)\) → 현지 수익률과 환율이 **음(−)의 상관**이면 환율이 오히려 위험을 줄일 수 있음
- 환헤지: 선물환 매도 등으로 환위험 제거. 헤지 비용·기회손실 존재 → 완전 헤지가 항상 최선은 아님
- **자국편향(Home bias)**: 정보 비대칭, 거래비용·세금, 제도적 제약 등으로 자국 자산을 과다 보유하는 현상

!!! warning "자주 나오는 함정"
    - 국제분산투자로 **모든** 위험이 제거되는 것은 아님(세계 공통의 체계적 위험은 남음)
    - 환율 변동은 항상 위험을 키우는 게 아니다 — 상관관계 부호에 따라 달라짐

## 2. 국제 증권시장 <span class="star s3">★★★</span> { #ch2 }

**출제 포인트:** 국제채권의 종류(유로채·외국채)와 명칭, 예탁증서(DR), 주요국 시장·미국 국채 구분 등 암기형 문제.

- 국제채권 구분

| 구분 | 정의 | 특징 |
|---|---|---|
| **외국채** | 외국 발행자가 **발행국 통화**로 그 나라 시장에서 발행 | 발행국 규제·공시 적용 |
| **유로채** | 표시통화 국가 **밖**에서 발행 (예: 미국 밖에서 발행되는 달러채 = 유로달러채) | 규제 적음, 주로 **무기명식**, 발행 절차 간편 |

- 외국채 별칭: **양키본드**(미국·달러), **사무라이본드**(일본·엔), **불독본드**(영국·파운드), **아리랑본드**(한국·원), 판다본드(중국·위안)
- 김치본드: 국내 시장에서 **외화**로 발행되는 채권 (최신 기본서 분류 확인)
- 예탁증서(DR): 해외 투자자가 거래할 수 있도록 예탁기관이 원주를 근거로 발행하는 증서
    - **ADR**: 미국 시장에서 달러로 거래, **GDR**: 미국·유럽 등 복수 시장, EDR: 유럽 시장
- 미국 국채 구분

| 종류 | 만기 | 이자 |
|---|---|---|
| T-Bill | 1년 이하 | **할인채** |
| T-Note | 1년 초과~10년 | 이표채 |
| T-Bond | 10년 초과 | 이표채 |
| TIPS | — | 원금이 물가에 연동 |

- STRIPS: 국채의 원금·이자를 분리해 각각 할인채로 거래

!!! warning "자주 나오는 함정"
    - "유로채는 유럽 통화로 발행하는 채권" → 틀림. **표시통화국 밖**에서 발행되는 채권
    - 양키본드는 유로채가 아니라 **외국채**
    - T-Bill은 이표채가 아니라 할인채

## 3. 해외 증권투자전략 <span class="star s2">★★</span> { #ch3 }

**출제 포인트:** 해외 포트폴리오 구성 방식(하향식·상향식, 적극적·소극적)과 환헤지·벤치마크 개념을 묻는다.

- **하향식(Top-down)**: 국가·통화 배분을 먼저 결정 → 산업 → 종목. 국가 요인이 수익률에 중요하다고 볼 때
- **상향식(Bottom-up)**: 국가보다 개별 기업·산업 분석 중심. 글로벌 산업 요인이 중요해질수록 유효
- 소극적 전략: 글로벌 지수(MSCI ACWI·World·EM 등) 추종 / 적극적 전략: 국가·종목 선택, 시점 선택으로 초과수익 추구
- MSCI 지수: **유동주식(free float) 기준 시가총액 가중**, 선진·신흥·프런티어 시장 분류
- 국가 배분 시 고려: 경제성장, 시장 규모·유동성, 환율 전망, 정치·제도 위험(컨트리 리스크)
- 환헤지 전략: 완전 헤지 / 무헤지 / 부분·선택적 헤지 — 헤지 비용(양국 금리차)과 상관관계를 함께 고려

!!! warning "자주 나오는 함정"
    - 하향식과 상향식의 출발점(국가 vs 종목)을 서로 바꿔 출제
    - 국가 간 경제 통합이 진전될수록 **산업(글로벌 섹터) 요인**의 중요성이 커진다
