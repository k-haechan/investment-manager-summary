    헤지펀드는 전략 분류(차익거래형/이벤트드리븐/방향성)와 "무엇을 사고 무엇을 공매도하는가"를, 신용파생은 "누가 위험을 넘기고 누가 프리미엄을 받는가"를 정리하면 대부분 풀린다.
    부동산·특별자산은 1과목 부동산 단원과 겹치므로 용어 확인 수준이면 충분하다.

## 1. 대안투자상품 <span class="star s2">★★</span> { #ch1 }

**출제 포인트:** 전통 투자(주식·채권)와 비교한 대안투자의 특징을 "옳은/틀린 것" 고르기로 묻는다.

- 대상: 부동산, PEF, 헤지펀드, 특별자산(상품·인프라 등), 신용구조화상품 등
- 대안투자의 일반적 특징

| 구분 | 내용 |
|---|---|
| 상관관계 | 전통자산과 **상관관계가 낮아** 분산효과가 기대됨 |
| 유동성 | 낮음, 환매 제한·장기 투자(투자기간 길음) |
| 수수료 | 운용보수 + 성과보수로 상대적으로 **높음** |
| 평가 | 시장가격이 없어 **공정가치 평가가 어렵고** 평가가 주관적 |
| 벤치마크 | 적절한 벤치마크 설정이 어려움, 절대수익 추구 |
| 운용 | 운용자의 전문성(역량)에 대한 의존도 높음, 레버리지·파생상품 활용 |

- 과거 성과 데이터는 생존편의(survivorship bias) 등으로 **과대평가**될 수 있다.

!!! warning "자주 나오는 함정"
    - "대안투자는 유동성이 높다", "수수료가 낮다", "벤치마크 설정이 쉽다" → 모두 틀림
    - 대안투자도 "위험이 낮다"는 보장이 아니다. 낮은 것은 전통자산과의 **상관관계**다.

## 2. 부동산 투자 <span class="star s2">★★</span> { #ch2 }

**출제 포인트:** 투자 방식 구분과 감정평가 방법(특히 수익환원법) 개념을 묻는다.

- 투자 방식: **직접 투자 vs 간접 투자**(부동산펀드·리츠), **지분형(Equity) vs 대출형(Debt)**
- 감정평가 3방식: 원가방식(원가법), 비교방식(거래사례비교법), 수익방식(수익환원법)
- 수익환원법(직접환원법):

\[ \text{부동산가치} = \frac{\text{순영업소득(NOI)}}{\text{환원율(Cap rate)}} \]

- 소득 흐름: 가능총소득 − 공실·대손 + 기타소득 = 유효총소득, 유효총소득 − 영업경비 = **NOI**
- 레버리지 효과: 총자본수익률 > 차입이자율이면 차입이 자기자본수익률을 **높인다**(반대면 낮춤).
- 주요 위험: 유동성 위험, 사업위험(시장·운영), 금융위험(차입), 법적위험

!!! warning "자주 나오는 함정"
    - 환원율이 **오르면** 부동산가치는 **떨어진다**(분모 증가).
    - 영업경비에 **부채서비스액(원리금 상환)·소득세는 포함하지 않는다**.

## 3. PEF(Private Equity Fund) <span class="star s3">★★★</span> { #ch3 }

**출제 포인트:** PEF의 구조(GP·LP), 투자전략(Buyout·VC 등), 투자회수(Exit) 방법, 2021년 사모펀드 제도 개편 내용을 묻는다.

- 2021년 자본시장법 개정으로 사모펀드는 **일반 사모집합투자기구**(기존 전문투자형)와 **기관전용 사모집합투자기구**(기존 경영참여형 PEF)로 재편
- 법적 형태: **합자회사**형 — 무한책임사원(**GP**, 업무집행)과 유한책임사원(**LP**, 출자자)
- 운용 흐름: 출자약정 → 투자 시 필요자금을 나눠 납입(**Capital Call**) → 투자·가치제고 → 회수(Exit)
- **J-커브 효과**: 초기에는 보수·비용 부담과 투자 미실현으로 수익률이 음(−)이다가, 회수기에 수익률이 상승

| 투자전략 | 내용 |
|---|---|
| Buyout | 경영권 인수 후 가치제고, **LBO**(인수대상 자산·현금흐름을 담보로 차입), MBO(경영진 인수) |
| Venture Capital | 초기·성장 단계 기업 지분 투자 |
| Mezzanine | 후순위채·CB·BW 등 부채와 지분의 중간 형태 |
| Distressed | 부실기업·부실채권 투자 후 구조조정 |

- LBO는 보통 인수목적회사(SPC)를 설립해 차입하고 인수 후 합병하는 구조 → 높은 레버리지
- **Exit 방법**: 매각(M&A, Trade sale), 기업공개(IPO), 세컨더리 매각(다른 PEF 등), 유상감자·배당을 통한 자금 회수(Recapitalization)
- 성과보수는 허들레이트(기준수익률) 초과분에 대해 GP가 받는 구조가 일반적

!!! warning "자주 나오는 함정"
    - **업무집행은 GP**, LP는 유한책임 출자자 — 역할을 바꿔 출제
    - 출자금은 약정 시점에 한 번에 내는 것이 아니라 **Capital Call 때마다** 납입
    - 세부 규제 수치(투자 한도·사원 수 등)는 개정이 잦으므로 (최신 기본서 확인)

## 4. 헤지펀드 <span class="star s3">★★★</span> { #ch4 }

**출제 포인트:** 전략 분류와 각 전략의 포지션 구성(무엇을 매수·공매도하는지), 헤지펀드 지수의 편의, 프라임 브로커 역할이 반복 출제된다.

| 분류 | 전략 | 포지션 핵심 |
|---|---|---|
| 차익거래형 | **전환사채 차익거래** | CB **매수** + 기초주식 **공매도**(델타 헤지) |
| | 채권 차익거래 | 관련 채권 간 가격 괴리 이용 |
| | 주식 시장중립형 | 롱·숏의 **베타 가중 금액**을 맞춰 시장위험 제거(롱 금액×롱 베타 = 숏 금액×숏 베타). 금액만 같으면 베타가 남을 수 있음 |
| 이벤트 드리븐 | **합병차익거래** | **피인수기업 매수** + **인수기업 공매도** |
| | 부실채권(Distressed) | 파산·구조조정 기업 증권 저가 매수 |
| 방향성 | 주식 롱숏 | 순노출(롱−숏)만큼 시장 방향성 보유 |
| | **글로벌 매크로** | 거시경제 전망으로 주식·채권·통화·상품 방향성 베팅, 레버리지, 하향식 |
| | 이머징마켓 / 선물(CTA) | 신흥시장 투자, 추세추종 선물매매 |
| 기타 | 펀드 오브 헤지펀드 | 여러 헤지펀드에 분산, 보수 이중 부과 |

- 보수: 운용보수 + 성과보수, **하이워터마크**(과거 최고 순자산 회복 전에는 성과보수 없음), 허들레이트
- 헤지펀드 지수의 편의: **생존편의**(청산 펀드 제외), **자기선택편의**(성과 좋은 펀드만 보고), **즉시기록편의(backfill)** → 성과가 **과대평가**
- 프라임 브로커: 신용공여(레버리지), **증권대차(공매도 지원)**, 청산·결제, 자산보관, 리포팅 등 종합 서비스
- 리스크: 레버리지·유동성·운용역(키맨) 위험, 낮은 투명성

!!! warning "자주 나오는 함정"
    - 합병차익거래에서 **인수기업을 매수**한다고 바꿔 냄 → 틀림(피인수기업 매수)
    - 전환사채 차익거래는 CB를 **매수**하고 주식을 공매도(반대로 출제됨)
    - 글로벌 매크로는 차익거래형이 아니라 **방향성 전략**
    - 지수 편의들은 성과를 **과소**가 아니라 **과대**평가하게 만든다

## 5. 특별자산 펀드 <span class="star s1">★</span> { #ch5 }

**출제 포인트:** 특별자산펀드의 정의와 투자 대상을 단순 확인하는 문제.

- 자본시장법상 집합투자기구 5종: 증권, 부동산, **특별자산**, 혼합자산, 단기금융(MMF)
- 특별자산펀드: 집합투자재산의 **50%를 초과**하여 증권·부동산을 **제외한** 경제적 가치가 있는 자산(일반상품, 선박·항공기, 인프라, 지적재산권 등)에 투자
- 상품(커머디티) 투자: 선물 이용 시 **콘탱고**(선물가 > 현물가)에서는 롤오버 손실, **백워데이션**에서는 롤오버 이익 가능
- 인프라(SOC): BTO(이용자 사용료로 회수), BTL(정부 임대료로 회수)

## 6. Credit Structure <span class="star s2">★★</span> { #ch6 }

**출제 포인트:** 신용파생상품(CDS·TRS·CLN·CDO)의 구조와 위험 이전 방향, 프리미엄 결정요인, CDO 트랜치 특성을 묻는다.

| 상품 | 구조 |
|---|---|
| **CDS** | 보장매입자가 프리미엄 지급, 신용사건(파산·지급불이행·채무재조정 등) 발생 시 보장매도자가 손실 보전 |
| **TRS** | 총수익지급자가 준거자산의 총수익(이자+가격변동)을 넘기고 기준금리+스프레드를 받음 → **시장위험과 신용위험 모두 이전** |
| **CLN** | CDS를 내재한 채권. 보장매입자가 발행하고 투자자가 보장매도자 역할(고금리 대가로 신용위험 부담) |
| **CDO** | 채권·대출 풀을 트랜치(선순위·메자닌·에쿼티)로 나눠 발행. 손실은 **에쿼티부터** 흡수 |

- CDS 프리미엄 상승 요인: 준거자산 **부도확률↑**, **회수율↓**, 보장매도자 **신용등급↑**, 준거자산과 보장매도자 간 **상관관계↓**
- Basket CDS(First-to-default): 기초자산 간 **상관관계가 낮을수록** 하나라도 부도날 확률이 커져 프리미엄↑
- CDO: 자산 간 상관관계↑ → **에쿼티 트랜치에 유리**, 선순위 트랜치에 불리
- 현금흐름형 CDO(실제 자산 이전) vs **합성형 CDO**(CDS로 신용위험만 이전)

!!! warning "자주 나오는 함정"
    - TRS는 신용위험**만** 이전하는 것이 아니다(시장위험 포함)
    - CLN 투자자는 보장**매도자** 포지션
    - FTD 바스켓은 상관관계가 **높을수록** 프리미엄이 높다고 바꿔 출제
