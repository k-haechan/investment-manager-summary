## 1. 리스크와 리스크 관리의 필요성 <span class="star s1">★</span> { #ch1 }

**출제 포인트:** 리스크 유형의 정의를 구분하는 단순 문제.

| 유형 | 정의 |
|---|---|
| 시장 리스크 | 주가·금리·환율·상품가격 변동으로 인한 손실 |
| 신용 리스크 | 거래상대방의 채무불이행·신용도 하락으로 인한 손실 |
| 유동성 리스크 | 자산을 적정 가격에 처분하지 못하거나 자금 조달이 어려운 위험 |
| 운영 리스크 | 부적절한 내부 절차·인력·시스템, 외부 사건으로 인한 손실 |
| 법적 리스크 | 계약의 법적 효력 미비 등으로 인한 손실 |

- 필요성: 금융시장 변동성 확대, 파생상품 거래 증가, 감독기관(바젤) 자기자본 규제

## 2. 시장 리스크(Market Risk)의 측정 <span class="star s3">★★★</span> { #ch2 }

**출제 포인트:** VaR 계산(신뢰수준·보유기간 변환, 포트폴리오 VaR, 채권·옵션 VaR)과 VaR 측정방법별 장단점 비교가 매회 핵심이다.

- **VaR**: 정상적인 시장에서 **주어진 신뢰수준**으로 **목표기간** 동안 발생할 수 있는 **최대 손실금액**
- 정규분포 가정 시 신뢰수준 상수 \(\alpha\): **95% → 1.65**, **99% → 2.33**

\[ VaR = \alpha \times \sigma \times V \times \sqrt{t} \]

  (\(\sigma\): 일별 수익률 표준편차, \(V\): 포지션 가치, \(t\): 보유기간(일)) — 평균수익률을 0으로 보고, 일별 수익률이 서로 **독립**이라는 전제의 근사식입니다.
- 신뢰수준 변환: \( VaR_{99\%} = VaR_{95\%} \times 2.33 / 1.65 \) / 기간 변환: \( VaR_{t\text{일}} = VaR_{1\text{일}} \times \sqrt{t} \)
- **포트폴리오 VaR**(두 자산)

\[ VaR_P = \sqrt{VaR_1^2 + VaR_2^2 + 2\rho\,VaR_1 VaR_2} \]

- \(\rho = 1\): 개별 VaR의 단순합 / \(\rho = -1\): 차이의 절댓값 / \(\rho < 1\)이면 분산효과 발생
- 분산효과 = 개별 VaR 합계 − 포트폴리오 VaR
- 채권 VaR: \( \alpha \times P \times MD \times \sigma(\Delta y) \) (MD: 수정듀레이션, \(\sigma(\Delta y)\): 금리변동 표준편차)
- 옵션 VaR(델타-노말): \( |\Delta| \times \text{기초자산 VaR} \) — 델타는 **절댓값**(풋은 델타가 음수), 옵션 가격(프리미엄) 자체는 필요 없음
- 측정방법 비교

| 방법 | 평가 방식 | 장점 | 단점 |
|---|---|---|---|
| **델타-노말**(분석적 분산-공분산) | 부분가치평가 | 계산 간단·빠름 | 정규분포 가정(두꺼운 꼬리 무시), **옵션 등 비선형 위험 과소평가** |
| **역사적 시뮬레이션** | 완전가치평가 | 분포 가정 불필요, 비선형·두꺼운 꼬리 반영 | 과거 한 경로에만 의존, 자료 기간에 민감 |
| **몬테카를로 시뮬레이션** | 완전가치평가 | 가장 유연·정확, 비선형·다양한 분포 반영 | 계산 비용 큼, **모형 리스크** |
| **스트레스 테스트** | 시나리오 분석 | 극단적 상황 손실 파악, VaR 보완 | 시나리오 주관적, 상관관계 반영 어려움 |

- 델타-노말 보완: 감마까지 반영하는 **델타-감마** 방법
- 바젤(구 시장위험 기준) 내부모형: **보유기간 10일, 신뢰수준 99%**, 승수 **3 이상** 적용. 개정 시장위험 체계(FRTB)는 **97.5% 기대부족액(ES)**을 씀 (기본서 수록 기준 확인) / **사후검증(Backtesting)**: 실제 손실이 VaR를 초과한 횟수로 모형 검증(통상 250영업일 기준, 구간별 예외 허용 횟수는 최신 기본서 확인)
- VaR의 한계: VaR를 초과하는 **꼬리 손실 규모**를 알려주지 않음 → **기대부족액**(Expected Shortfall, VaR를 넘는 꼬리 손실의 평균) 등 보완. 신용리스크의 기대손실(EL)과 다른 개념

**예시** — 주식 100억원, 일별 \(\sigma = 2\%\), 99%:

\[ VaR_{1\text{일}} = 2.33 \times 0.02 \times 100\text{억} = 4.66\text{억}, \qquad VaR_{10\text{일}} = 4.66\text{억} \times \sqrt{10} \approx 14.74\text{억} \]

!!! warning "자주 나오는 함정"
    - 보유기간 환산은 \(t\)가 아니라 \(\sqrt{t}\)를 곱한다
    - 상관계수가 낮을수록(음수일수록) 포트폴리오 VaR가 **작아진다**
    - "델타-노말 방법은 옵션 포지션 위험을 정확히 측정한다" → 틀림(비선형성 반영 불가)
    - "역사적 시뮬레이션은 정규분포를 가정한다" → 틀림

## 3. 신용 리스크(Credit Risk)의 측정 <span class="star s3">★★★</span> { #ch3 }

**출제 포인트:** 기대손실 계산, 채권 수익률로 부도확률 구하기, 신용리스크 모형 구분, 장외파생상품 신용노출이 나온다.

- **기대손실(EL)** = **EAD × PD × LGD**, \( LGD = 1 - \text{회수율} \)
    - EL은 대손충당금(가격)으로, **비기대손실(UL)**은 자기자본으로 대비
- 위험중립 부도확률(1년 무위험이자율 \(r\), 위험채권 수익률 \(y\), 회수율 \(R\))

\[ p = \frac{1 - \dfrac{1+r}{1+y}}{1 - R} \qquad (R = 0 \text{이면 } p = 1 - \tfrac{1+r}{1+y}) \]

  예: \(r = 5\%\), \(y = 10\%\), \(R = 0\) → \(p = 1 - 1.05/1.10 \approx 4.55\%\)
- 누적부도율 = 1 − 각 연도 생존율(1 − 한계부도율)의 곱
- 신용리스크 모형: **CreditMetrics**(신용등급 전이행렬 기반), **KMV**(머튼 구조모형, 부도거리), **CreditRisk+**(부도 여부만 고려하는 보험수리적 모형), CreditPortfolioView(거시경제 변수 반영) / 부도 예측: Altman Z-score 등 판별분석 모형
- 장외파생상품 신용노출 = **현재노출**(대체비용, 양(+)의 시장가치) + **잠재노출**
    - **옵션 매도자는 신용리스크가 없다**(프리미엄을 이미 받음) — 매입자만 노출
    - 금리스왑의 잠재노출은 만기 **중간 무렵** 최대, 통화스왑은 원금 교환 때문에 **만기 무렵** 최대
- 신용리스크 감축: 네팅(상계), 담보, 신용한도, 신용파생상품, 증거금

!!! warning "자주 나오는 함정"
    - 회수율과 LGD 혼동 — 회수율 40%면 LGD는 60%
    - 옵션 **매도** 포지션에 신용리스크가 있다고 출제 → 틀림
    - 네팅은 신용노출을 **줄인다**
