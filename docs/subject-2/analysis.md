## 1. 증권분석의 개념 및 기본체계 <span class="star s1">★</span> { #ch1 }

**출제 포인트:** 기본적 분석과 기술적 분석의 차이, 분석 순서를 묻는 개념 문제.

- **기본적 분석**: 경제·산업·기업 분석으로 **내재가치**를 추정해 시장가격과 비교(과소평가 매수·과대평가 매도)
- **기술적 분석**: 과거 가격·거래량 패턴으로 매매 시점 포착
- 하향식(Top-down): 경제 → 산업 → 기업 / 상향식(Bottom-up): 기업에서 출발
- 기본적 분석은 "무엇을 살 것인가", 기술적 분석은 "언제 살 것인가"에 강점

## 2. 유가증권의 가치평가 <span class="star s3">★★★</span> { #ch2 }

**출제 포인트:** 배당평가모형(특히 정률성장모형)으로 주가·성장률·요구수익률을 계산하는 문제가 반복된다.

- 기본 원리: 증권 가치 = 미래 현금흐름을 **요구수익률**로 할인한 현재가치
- 요구수익률은 CAPM으로 추정: \( k = r_f + \beta\,(E(R_m) - r_f) \)
- 배당평가모형

| 모형 | 식 | 비고 |
|---|---|---|
| 제로성장 | \( P_0 = D / k \) | 배당 일정 |
| **정률성장(고든)** | \( P_0 = D_1 / (k-g) \) | **k > g** 일 때만 성립 |
| 다단계 성장 | 고성장기 배당 현가 + 이후 정률성장 가치의 현가 | |

- \( D_1 = D_0(1+g) \) — 문제에서 "올해 배당"인지 "내년 예상 배당"인지 꼭 구분
- 지속가능 성장률: **g = b × ROE** (b: 사내유보율 = 1 − 배당성향)
- 정률성장모형에서 주가 상승 요인: 요구수익률(k)↓, 성장률(g)↑, 배당↑
- 성장기회의 현재가치(PVGO): \( P_0 = E_1/k + \text{PVGO} \) → ROE > k 일 때만 유보·재투자가 주가를 높인다

**예시** — \(D_0 = 1{,}000\)원, \(g = 5\%\), \(k = 10\%\):

\[ P_0 = \frac{1{,}000 \times 1.05}{0.10 - 0.05} = 21{,}000\text{원} \]

!!! warning "자주 나오는 함정"
    - 분자에 \(D_0\)를 그대로 넣는 실수 — 반드시 \(D_1\)
    - ROE < k 인 기업은 유보율을 높일수록 주가가 **하락**
    - 성장률이 요구수익률 이상이면 정률성장모형 적용 불가

## 3. 기업분석(재무제표분석) <span class="star s3">★★★</span> { #ch3 }

**출제 포인트:** 재무비율 계산·해석, 듀퐁 분해, 레버리지도 계산이 출제된다. 수험 후기에서 "ratio 정리"를 핵심으로 꼽는 챕터.

| 구분 | 비율 | 식 |
|---|---|---|
| 안정성 | 유동비율 | 유동자산 / 유동부채 |
| | 당좌비율 | (유동자산 − 재고자산) / 유동부채 |
| | 부채비율 | 부채 / 자기자본 |
| | 이자보상비율 | 영업이익 / 이자비용 |
| 수익성 | ROA | 순이익 / 총자산 |
| | ROE | 순이익 / 자기자본 |
| 활동성 | 총자산회전율 | 매출액 / 총자산 |
| | 재고자산회전율 | 매출액 / 재고자산 |
| | 매출채권회전율 | 매출액 / 매출채권 |
| 성장성 | 매출액·순이익 증가율 | (당기 − 전기) / 전기 |

- **듀퐁 분해**

\[ ROE = \frac{\text{순이익}}{\text{매출액}} \times \frac{\text{매출액}}{\text{총자산}} \times \frac{\text{총자산}}{\text{자기자본}} \]

- 즉 ROE = 매출액순이익률 × 총자산회전율 × 재무레버리지(= 1 + 부채비율)
- 레버리지 분석

\[ DOL = \frac{\text{영업이익 변화율}}{\text{매출액 변화율}} = \frac{\text{매출액}-\text{변동비}}{\text{영업이익}}, \qquad DFL = \frac{\text{EPS 변화율}}{\text{영업이익 변화율}} = \frac{\text{영업이익}}{\text{영업이익}-\text{이자비용}} \]

- 결합레버리지 \( DCL = DOL \times DFL \)
- 고정영업비가 클수록 DOL↑, 이자비용(타인자본)이 클수록 DFL↑
- 재무제표 분석의 한계: 과거 자료, 회계처리 방법 차이로 기업 간 비교 왜곡, 질적 정보 미반영

!!! warning "자주 나오는 함정"
    - 당좌비율은 유동자산에서 **재고자산**을 뺀다
    - 재무레버리지(총자산/자기자본)는 **1 + 부채비율**
    - 회전율은 높을수록 자산을 효율적으로 쓰는 것

## 4. 주식투자 <span class="star s3">★★★</span> { #ch4 }

**출제 포인트:** 상대가치평가 배수(PER·PBR·PSR·EV/EBITDA)의 정의·분해·장단점과 FCF·EVA 개념을 묻는다. (2장과의 내용 경계는 최신 기본서 확인)

- **PER** = 주가 / EPS. 정률성장모형에서 유도:

\[ \frac{P_0}{E_1} = \frac{1-b}{k-g}, \qquad \frac{P_0}{E_0} = \frac{(1-b)(1+g)}{k-g} \]

- → 배당성향↑, 성장률↑, 요구수익률↓ 이면 PER↑
- **PBR** = 주가 / BPS = **ROE × PER** = 순이익률 × 총자산회전율 × 재무레버리지 × PER
- **PSR** = 주가 / 주당매출액 — **적자 기업**·신생 기업에도 적용 가능
- **EV/EBITDA**: \( EV = \text{시가총액} + \text{순차입금}(\text{총차입금} - \text{현금성자산}) \)
    - 자본구조·감가상각 방법 차이의 영향을 덜 받아 기업 간 비교에 유리
- **토빈의 q** = 자산의 시장가치 / 대체원가. q > 1 이면 투자 유인, q < 1 이면 인수합병 대상이 되기 쉬움
- 잉여현금흐름: \( FCFF = EBIT(1-t) + \text{감가상각비} - \text{자본적지출} - \text{순운전자본 증가} \) → WACC로 할인해 기업가치 산출
- **EVA** = 세후영업이익(NOPAT) − WACC × 투하자본 = (ROIC − WACC) × 투하자본

!!! warning "자주 나오는 함정"
    - 적자 기업은 PER 산출이 무의미 → PBR·PSR 활용
    - EV에서 현금성자산은 **빼고** 차입금은 **더한다**
    - EVA > 0 의 조건은 ROIC > WACC (ROE와 혼동 금지)

## 5. 기술적 분석 <span class="star s2">★★</span> { #ch5 }

**출제 포인트:** 기술적 분석의 기본 가정과 한계를 고르는 문제.

- 기본 가정: 주가는 **수요·공급**에 의해 결정 / 주가는 **추세**를 따라 움직이며 지속 / 추세 변화는 수급 변화로 발생 / 차트 패턴은 **반복**된다
- 장점: 매매 **시점** 포착, 심리적 요인 반영, 재무제표 왜곡 영향 없음
- 한계: 과거 패턴 반복 가정의 비현실성, 해석의 **주관성**, 주가 변동 **원인 분석 불가**, 내재가치 무시
- 기술적 분석 유형: 추세분석, 패턴분석, 지표분석, 심리분석 등

!!! warning "자주 나오는 함정"
    - "기술적 분석은 시장 변동의 원인을 설명할 수 있다" → 틀림

## 6. 추세분석 <span class="star s2">★★</span> { #ch6 }

**출제 포인트:** 지지·저항, 이동평균선 해석, 갭의 종류를 묻는다.

- 지지선이 하향 돌파되면 **저항선**으로, 저항선이 상향 돌파되면 **지지선**으로 역할 전환
- 추세선은 접점이 많고 기간이 길수록, 기울기가 완만할수록 신뢰도↑
- 이동평균선: 단기선이 장기선을 상향 돌파 = **골든크로스**(매수), 하향 돌파 = **데드크로스**(매도)
- 이동평균 기간이 길수록 추세 신뢰도↑, 반응 속도↓
- 갭의 종류: 보통갭 / **돌파갭**(새 추세 시작) / **급진갭(중간갭·측정갭)**(추세 중간) / **소멸갭**(추세 막바지), 섬꼴반전

!!! warning "자주 나오는 함정"
    - 돌파갭은 추세의 **시작**, 소멸갭은 추세의 **끝** — 순서를 섞어 출제

## 7. 패턴 분석 <span class="star s2">★★</span> { #ch7 }

**출제 포인트:** 주어진 패턴이 반전형인지 지속형인지 분류하는 문제가 대표적이다.

| 반전형 | 지속형 |
|---|---|
| 헤드앤숄더(머리어깨형)·역헤드앤숄더 | 삼각형(대칭·상승·하락) |
| 이중천정(M)·이중바닥(W)·삼중천정 | 깃발형(Flag) |
| 원형천정·원형바닥 | 페넌트형(Pennant) |
| V자형(스파이크) | 쐐기형(Wedge) |
| 확대형 | 직사각형 |

- 헤드앤숄더: **목선(neckline) 하향 돌파**로 패턴 완성, 목표치 = 머리~목선 거리를 돌파점에서 아래로 투영
- 패턴 형성 기간이 길고 거래량이 수반될수록 신뢰도↑

!!! warning "자주 나오는 함정"
    - 삼각형·깃발형·쐐기형을 반전형으로 분류한 보기 → 틀림(기본서 분류 기준)

## 8. 캔들 차트 분석 <span class="star s2">★★</span> { #ch8 }

**출제 포인트:** 캔들 패턴 이름과 의미(상승 반전/하락 반전)를 연결하는 문제.

| 상승 반전(바닥권) | 하락 반전(천정권) |
|---|---|
| 망치형(Hammer) | 교수형(Hanging man) |
| 역망치형 | 유성형(Shooting star) |
| 상승장악형 | 하락장악형 |
| 관통형 | 먹구름형 |
| 샛별형(Morning star) | 석별형(Evening star) |
| 적삼병 | 흑삼병(까마귀) |

- 망치형과 교수형은 **모양이 같고 위치(추세)만 다르다**
- 도지(Doji): 시가 = 종가, 매수·매도 세력 균형 → 추세 전환 가능성
- 장악형: 둘째 날 몸통이 첫째 날 몸통을 **완전히 감싸는** 형태 / 잉태형: 반대로 둘째 날 몸통이 첫째 날 몸통 **안에** 들어감

!!! warning "자주 나오는 함정"
    - 교수형을 상승 신호로, 샛별형을 하락 신호로 바꿔 출제

## 9. 지표 분석 <span class="star s3">★★★</span> { #ch9 }

**출제 포인트:** 각 지표의 산식·과매수/과매도 기준과 지표 분류(추세·모멘텀·거래량·심리)를 묻는다.

| 분류 | 지표 | 핵심 |
|---|---|---|
| 추세 | **MACD** | 단기 지수이동평균 − 장기 지수이동평균, 시그널선 교차로 매매 |
| 모멘텀(오실레이터) | **RSI** | 70 이상 과매수, 30 이하 과매도 |
| | **스토캐스틱** | 최근 n일 고가·저가 범위 중 현재가 위치 |
| | **이격도** | 주가 / 이동평균 × 100 |
| 거래량 | **OBV** | 상승일 거래량 더하고 하락일 거래량 빼서 누적 |
| | **VR** | (상승일 거래량 + 보합일 거래량/2) ÷ (하락일 거래량 + 보합일 거래량/2) × 100 |
| 심리 | **투자심리선** | 최근 **10일** 중 상승일수 비율 |

- RSI(통상 14일):

\[ RSI = \frac{\text{n일간 상승폭 합계}}{\text{n일간 상승폭 합계} + \text{n일간 하락폭 합계}} \times 100 \]

- 스토캐스틱 \( \%K = \dfrac{C - L_n}{H_n - L_n} \times 100 \) (\(C\): 당일 종가, \(H_n, L_n\): n일 최고·최저가)
- 투자심리선: **75% 이상 과열**, **25% 이하 침체**
- VR: 보합일 거래량은 상승·하락 쪽에 절반씩 배분. 과열·침체 기준값은 (최신 기본서 확인)
- 주가와 지표 방향이 엇갈리는 **다이버전스**는 추세 전환 신호

!!! warning "자주 나오는 함정"
    - OBV·VR은 **거래량** 지표, RSI·스토캐스틱은 **모멘텀** 지표 — 분류를 섞어 출제
    - 투자심리선 기준 기간은 10일

## 10. 엘리어트 파동이론 <span class="star s3">★★★</span> { #ch10 }

**출제 포인트:** 절대불가침 법칙, 파동 개수, 파동별 특징, 피보나치 비율을 묻는다.

- 1 사이클 = **상승 5파(1~5파, 충격파 1·3·5 / 조정파 2·4) + 하락 3파(a·b·c)** = **8개 파동**
- 세분하면 **34개**, 더 세분하면 **144개** (피보나치 수열)
- **절대불가침 법칙**
    1. **2파**의 저점은 **1파의 시작점** 아래로 내려갈 수 없다
    2. **3파**는 1·3·5파 중 **가장 짧은 파동이 될 수 없다**
    3. **4파**의 저점은 **1파의 고점**과 겹칠 수 없다
- 파동별 특징

| 파동 | 특징 |
|---|---|
| 1파 | 바닥에서 출발, 5개 중 짧은 경우가 많음 |
| 2파 | 1파의 0.382 또는 0.618 되돌림 |
| **3파** | 가장 강하고 긴 경우가 많음, **거래량 최대**, 갭 출현·연장 빈번 |
| 4파 | 3파의 0.382 되돌림이 일반적, 2파와 반대 형태 경향(교대의 법칙) |
| 5파 | 3파보다 거래량이 적은 경우가 많음 |
| a파 | 하락 시작, 5개 소파동으로 구성 |
| b파 | 일시 반등 — 매도 기회(함정) |
| c파 | 강한 하락, 투매 |

- 피보나치 비율: **0.382, 0.618, 1.618**
- **연장파**는 충격파(1·3·5파) 중 **하나**에서만 나타나는 것이 일반적
- 한계: 파동의 시작·끝 판단이 **주관적**

!!! warning "자주 나오는 함정"
    - "3파는 가장 길어야 한다" → 정확히는 **가장 짧으면 안 된다**
    - "4파는 1파의 시작점을 침범할 수 없다" → 4파의 기준은 1파의 **고점**(시작점은 2파 기준)

## 11. 산업분석 개요 <span class="star s1">★</span> { #ch11 }

**출제 포인트:** 산업분석의 의의를 묻는 단순 개념 문제.

- 산업분석은 경제분석과 기업분석을 잇는 단계 — 같은 경제 여건에서도 산업마다 성과가 다르기 때문에 필요
- 산업 분류: 한국표준산업분류(통계청) 등, 분석 목적에 따라 재분류
- 분석 항목: 산업구조 변화, 산업연관, 라이프사이클, 경기순환, 경쟁력, 정책

## 12. 산업구조 변화 분석 <span class="star s2">★★</span> { #ch12 }

**출제 포인트:** 경제발전에 따른 산업구조 변화 이론의 이름과 핵심 주장을 연결하는 문제.

- **페티-클라크 법칙**: 경제발전에 따라 산업 비중이 **1차 → 2차 → 3차 산업**으로 이동
- **호프만 법칙**: 공업화가 진행될수록 **소비재 산업 대비 자본재(생산재) 산업** 비중이 커짐 → 호프만 비율(소비재/자본재)이 **하락**
- 비교우위론(리카도): 상대적 생산비 차이로 무역·특화 발생
- 요소부존이론(헥셔-올린): **풍부한 생산요소**를 집약적으로 쓰는 재화에 비교우위
- 산업구조 변화 요인: 수요 측(소득 증가에 따른 소비구조 변화), 공급 측(기술혁신·생산요소 변화), 무역 구조 (세부 이론 범위는 최신 기본서 확인)

!!! warning "자주 나오는 함정"
    - 호프만 비율은 공업화 진행 시 **상승**이 아니라 **하락**

## 13. 산업연관분석(Input-Output Analysis) <span class="star s2">★★</span> { #ch13 }

**출제 포인트:** 산업연관표의 각 계수 정의와 전방·후방 연쇄효과 구분.

- 산업연관표: 산업 간 재화·서비스의 투입·산출 관계를 행렬로 기록(행 = 배분(산출), 열 = 투입 구조)
- **투입계수** \( a_{ij} = x_{ij} / X_j \): j산업 1단위 생산에 필요한 i산업 중간투입
- **생산유발계수**: 최종수요 1단위 증가 시 각 산업 생산 증가분 = 레온티에프 역행렬 \( (I - A)^{-1} \)
- **영향력계수** = **후방연쇄효과**(해당 산업 최종수요 증가가 전 산업에 미치는 영향, 역행렬 **열** 합 기준)
- **감응도계수** = **전방연쇄효과**(전 산업 최종수요 증가로 해당 산업이 받는 영향, 역행렬 **행** 합 기준)
- 그 외: 부가가치유발계수, 수입유발계수, 고용유발계수

!!! warning "자주 나오는 함정"
    - 영향력계수 ↔ 감응도계수, 전방 ↔ 후방을 바꿔 출제

## 14. 라이프사이클 분석(Life Cycle Analysis) <span class="star s2">★★</span> { #ch14 }

**출제 포인트:** 각 단계의 매출·이익·경쟁 특징을 단계와 연결하는 문제.

| 단계 | 특징 |
|---|---|
| 도입기 | 매출 미미, 적자 가능, 높은 위험·제품 홍보 비용 |
| 성장기 | 매출 **급증**, 이익 증가, 신규 진입 증가 — 투자 유망 단계 |
| 성숙기 | 매출 증가 둔화, 경쟁 심화로 이익률 하락, 시장점유율 경쟁·원가 절감 중요 |
| 쇠퇴기 | 수요 감소, 이익 감소·적자, 사업 철수·다각화 |

- 성장기 후반~성숙기에는 가격 경쟁과 제품 차별화가 중요해짐

!!! warning "자주 나오는 함정"
    - "성숙기에 신규 진입이 가장 활발하다" → 틀림(성장기)

## 15. 경기순환 분석(Business Cycle Analysis) <span class="star s2">★★</span> { #ch15 }

**출제 포인트:** 경기민감·경기방어 산업 구분과 경기지표(BSI 등) 해석.

- 경기민감 산업: 자동차, 건설, 철강, 화학 등 내구재·자본재 / 경기방어 산업: 음식료, 의약품, 전력·가스 등 필수소비재·유틸리티
- 경기종합지수: **선행**(장단기 금리차, 건설수주액, 코스피 등), **동행**(광공업생산, 소매판매액, 비농림어업취업자수 등), **후행**지수로 구성 — 구성지표는 개편되므로 (최신 기본서 확인)
- 기업경기실사지수:

\[ BSI = \frac{\text{긍정 응답 업체 수} - \text{부정 응답 업체 수}}{\text{전체 응답 업체 수}} \times 100 + 100 \]

- BSI 100 초과 → 경기를 **긍정적으로 보는 업체가 더 많음**(확장 기대), 100 미만 → 부정적 응답이 더 많음. 실제 경기국면을 확정하는 지표는 아님
- 소비자심리지수(CSI)도 100을 기준으로 해석

!!! warning "자주 나오는 함정"
    - BSI 범위는 0~200, 기준은 **100** (0 기준 아님)

## 16. 산업경쟁력 분석 <span class="star s2">★★</span> { #ch16 }

**출제 포인트:** 포터의 5가지 경쟁요인과 다이아몬드 모형 구성요소를 묻는다.

- **포터의 5 Forces**: 기존 기업 간 경쟁, **신규 진입자 위협**, **대체재 위협**, **구매자 교섭력**, **공급자 교섭력**
- 진입장벽: 규모의 경제, 제품 차별화, 대규모 자본 소요, 유통경로 확보, 정부 규제, 절대 비용우위
- **다이아몬드 모형**(국가 경쟁우위): 요소조건, 수요조건, 관련·지원 산업, 기업 전략·구조·경쟁 + 보조요인(정부, 기회)

!!! warning "자주 나오는 함정"
    - 5 Forces에 "정부"는 포함되지 않음(다이아몬드 모형의 보조요인)

## 17. 산업정책 분석 <span class="star s1">★</span> { #ch17 }

**출제 포인트:** 산업정책의 유형과 목적을 묻는 지엽적 문제.

- 산업정책: 시장실패를 보정하고 산업 경쟁력·구조 고도화를 위한 정부 개입
- 유형: **산업구조정책**(유망 산업 육성, 사양 산업 조정), **산업조직정책**(독과점 규제·경쟁 촉진)
